## 目的地

一份**可执行的 spec**（交给 `/to-spec` 折成构建计划）：会话名旁边有一个**关闭按钮** ——
在**平铺态的格标题行**、**标签态顶部页签条的标签**、**左栏「会话」页的会话行**三处，
**指针悬浮在那条会话上时**出现一个红色 `✖`，点它就**关掉那一会话**。

关闭动作与被它取代的左栏页顶 `关闭` 同源，但目标从「焦点行」改成「**被点的那一会话**」，
且**允许关前台**（关掉后前台落到相邻的一个会话）。左栏页顶那个 `关闭` 按钮随之**删掉**。

**范围**：`src/render/`（`tui.rs` / `wording.rs` / `palette.rs` / `layout.rs` / `keyboard.rs`）、
`src/session/host.rs` 的 `close_check`、`src/cli/interactive.rs` 的关闭与前台转移路径、
`CONTEXT.md` 的词条、`docs/render.md`、[`docs/tui-manual-checklist.md`](../../docs/tui-manual-checklist.md)、
被推翻条款所在的 [`session-tab/spec.md`](../session-tab/spec.md)、
帧断言所在的 `tests/render_layout.rs` 与 `tests/session_page.rs`。**事件流与模型可见文本零变化** ——
关闭不写收尾事件（既有事实，见 `session-tab` 票 07），本图不碰。

### 冻结项（charting 的 grilling 定下，票里不得重开）

1. **三处落点**：平铺态**格标题行**、标签态**顶部页签条的标签**、左栏**「会话」页的会话行**。
   三处**一致**：指针悬浮在那条会话上时出现一个红色 `✖`，点 `✖` 关掉**那一会话**。
2. **点谁关谁**：目标从「焦点行」改成「**被点的那一会话**」；**允许关前台**（推翻 `close_check` 的
   `Foreground` 拒绝）。
3. **忙时仍拒绝**：正在跑回合的那一会话点 `✖` → 不关，给回执（沿用既有 `Running` 拒绝）。
4. **关掉后重排**：平铺的槽位与页签条的标签**重排 / 左移**（跟着「槽位 = 宿主表前 N 个」的既有语义走），
   不留看起来像「那会话还在」的空位。
5. **前台落到相邻的一个会话**：关掉前台后，按宿主表顺序取**下一个**（没有就取**上一个**）；都没有 →
   既有的**空宿主态**。
6. **左栏会话页页顶的 `关闭` 按钮删掉**（连同 `关闭「<标题>」` 两档文案）；`新建` 与读数留在页顶。
7. **只在盘上、没装载的行不显示 `✖`**（那类行本来也关不掉 —— `close_check` 的 `NotHosted` 拒绝）。
8. **红色另立语义名**：不与 `BAD`（工具失败、会话错误）混用；色值取红。
9. **hover 判定范围 = 整行 / 整条标签**：指针落在那一行（那一格标题行、那一条标签）的任何位置都算。
10. **不做降级**：终端不按 `?1003h` 上报移动事件时，**按钮**永不出现（不常显、不另做一个键盘入口
    专治「按钮不出现」）；把「哪些终端会报」列进真机走查项。**2026-10-20 决策票补注**：另加的
    **两条键位**（全局 `Ctrl-X`、会话页内 `x`）是**独立入口**，不属降级 —— 在不支持鼠标的终端里
    照样能关会话，只是按钮不出现。

- [终端鼠标移动事件的真实行为：谁会报、报多少](issues/01-research-mouse-move-events.md) — **做悬浮不必新开
  鼠标模式**（crossterm 的 `EnableMouseCapture` 自带 `?1003h`，多数 ratatui 程序早开着）；**主流终端都
  实现 1003**（kitty / Alacritty / Ghostty / wezterm / foot / GNOME Terminal / Konsole / VS Code 集成
  终端；Windows Terminal 只到模式表层面、iterm2 只有应用级开关文档）；**转发链里 tmux 与 zellij 通、
  GNU screen 不通、herdr 默认不通**（herdr 自己抓鼠标，它那侧 `mouse_capture = false` 才放行）。
  **密度**：终端侧按 cell 去重，一次横扫 80 列 ≈ 80 个 `Moved`、上界 1920；crossterm 不节流，heng

  cb=160 被 crossterm 0.29 当解析错误丢弃；失焦要走 `?1004h`，heng 尚未发）。**hover 与拖选在事件层
  分得开**（cb=35 → `Moved`、cb=32 → `Drag(Left)`）。**没验成**：每个 GUI 终端是否真在 1003 下上报移动
  —— 本机 GL 起窗失败，笔记 §1 留了可复现的探测法。产物

- [三处落点的关闭按钮长什么样：几帧真字符](issues/02-prototype-close-button-shapes.md) — **7 帧 + 生成脚本
  + 读法**，维护者 2026-10-20 过帧拍板。**列账**：平铺格标题行 `✖` 在格内第 2 列、标题从第 4 列起、

## 范围之外

<!-- scope 边界，不是路线的一步：封闭的结论，永远不 graduate。 -->

- **hover 超时降级**（指针停着不动过一会儿就收起 `✖`）：它是唯一能盖「鼠标移出窗口而终端仍聚焦」的手段
  （协议里没有「指针离开」事件，kitty 的私有扩展被 crossterm 丢弃）—— 但会让读标题时按钮闪，
  [决策票](issues/03-grilling-close-contract.md) 选了「焦点事件 + 键盘即清」。
