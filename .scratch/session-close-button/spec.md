## 问题陈述

1. **关掉一个会话要两步，而且是间接的。** 左栏「会话」页页顶那个 `关闭` 作用于**焦点行**：要关掉一个
   非前台的会话，先点它落焦点、再点页顶 —— 而按钮在页顶，目标在列表里，中间隔着整个列表。
2. **平铺态与标签态没有关闭入口。** 平铺时每格只有一行标题（`◆ 标题`）；标签态的会话名在顶部页签条的
   标签里。两处都没有能点的关闭 —— 只开一个会话时更是无从下手。
3. **前台那一会话关不掉。** 关闭检查有一条「前台不许关自己」的拒绝（宿主表里不止一个时），回执是
   「先切到别的会话再关」—— 一步能关的事被写成两步。
4. **鼠标的移动事件已经在投递，却没人接。** 终端的鼠标捕获已经开了「任何事件上报」模式，渲染器只认
   5 种手势，**移动**落进兜底分支被丢掉 —— 悬浮类交互的地基是现成的，不用新开任何终端模式。
5. **一个协议级空洞**：xterm 协议里**没有「指针离开」事件**。任何悬浮类的界面都得自己想办法清掉最后
   一次坐标，否则按钮会黏在屏幕上不走。
6. **一次横扫能刷出成百上千个移动事件。** 终端按格去重之后，一次横扫 80 列仍是约 80 个事件，而渲染器
   现在是「一个事件一帧」—— 不合并的话，鼠标一动就是一串重画。

## 解决方案

会话名旁边有一个**关闭按钮**：在**平铺态的格标题行**、**标签态顶部页签条的标签**、**左栏「会话」页的
会话行**三处，**指针悬浮在那条会话上时**出现一个红色 `✖`，点它就**关掉那一会话**。

- 关闭的**目标从「焦点行」改成「被点的那一会话」** —— 一步关掉，不绕路。
- **允许关前台**：关掉之后**前台落到相邻的一个会话**（按宿主表顺序取下一个，没有就取上一个；都没有 →
  既有的空宿主态）。平铺态同一套规则：焦点格落到相邻格。
- 左栏「会话」页页顶那个 `关闭` 按钮**删掉**（页顶只剩读数与 `新建`），关闭入口改成三处 `✖`。
- 另给**两条键位**：全局 `Ctrl-X` 关掉前台那一会话、会话页内 `x` 关掉焦点行那一会话 —— 关闭从此不只走鼠标。
- 黏住的 `✖` 用**焦点事件**与**任意键盘输入**清掉；事件洪峰用**只在悬浮目标变化时才重画**合并。

## 用户故事

1. As 一个在左栏「会话」页里看列表的人, I want 把指针移到某一行就看见一个关闭标记, so that 我一眼就知道
   「关掉这一会话」是可能的、而且不用先点它落焦点。
2. As 一个想关掉某个**非前台**会话的人, I want 点那个关闭标记就直接关掉它, so that 我不必「点它 → 点页顶的
   `关闭`」绕两步。
3. As 一个想关掉**前台**那一会话的人, I want 也能直接关掉, so that 我不必先切到别的会话再回来关它。
4. As 一个关掉前台会话的人, I want 关完之后前台自动落到相邻的那一会话, so that 界面不会空在那里等我操作。
5. As 一个在**平铺态**里干活的人, I want 悬浮在某一格的标题上就看见它的关闭标记, so that 我不用把这一格
   切到前台再关。
6. As 一个关掉平铺里某一格的人, I want 焦点格落到相邻格、其余格重排, so that 平铺不会留下一格空位。
7. As 一个在**标签态**里干活的人, I want 顶部页签条的标签上也有那个关闭标记, so that 关掉一个会话不必
   绕到左栏去。
8. As 一个标签很多的人, I want 悬浮某个标签时**后面的标签不被推动**, so that 标签条不会每悬浮一次就抖一次。
9. As 一个**只用键盘**的人, I want 按一个键就关掉前台那一会话, so that 关闭不必依赖鼠标。
10. As 一个在左栏「会话」页里用键盘的人, I want 按 `x` 关掉焦点行那一会话, so that 我能在列表里键盘走一遍、
    顺手关掉某一个会话。
11. As 一个差点关错的人, I want 关闭**不二次确认**、按下去就关, so that 我不必多点一次；但我知道关掉的
    那一会话盘上还在、可以再装载。
12. As 一个关掉了**正在跑回合**的那一会话的人, I want 界面说清「它正在跑 · 先取消」并给我一个能点的
    「切到「…」」, so that 我知道该怎么继续而不是收到一句拒绝。
13. As 一个只想看看某个会话的人, I want 悬浮时**标题文字不被挤变形、后面的内容不动**, so that 我读标题
    的时候界面是稳的。
14. As 一个在窄屏（28 列左栏）里干活的人, I want 那里**也有**那个关闭标记, so that 窄档不是「没有关闭入口」
    的一档。
15. As 一个在**只读**会话（cwd 已不在、流只能半读）上悬停的人, I want 那个标记与普通行一样红, so that
    「这一下能关掉东西」在哪儿都是同一个意思。
16. As 一个只想看盘上历史、还没装载的会话的人, I want 那一行**没有**关闭标记, so that 我不会点一个注定
    不能按的按钮。
17. As 一个把指针移出终端窗口的人, I want 那个标记**不会黏在屏幕上**, so that 我看到的是当下的状态。
18. As 一个回到键盘工作的人, I want 敲任意键那个标记就消失, so that 界面不会留着一个我早就不看的东西。
19. As 一个用终端的人, I want 移动鼠标时**界面不刷屏**, so that 我划过一列标题不会看到几十次重画。
20. As 一个跑在 **herdr** 里的人, I want 知道那里的悬浮**不会出现**（herdr 默认自己抓鼠标）, so that 我不会
    以为界面坏了。

## 实现决定

### A. 关闭按钮与三处落点

1. **三处落点**：平铺态的**格标题行**、标签态**顶部页签条的标签**、左栏**「会话」页的会话行**。
2. **悬浮才现**：指针落在那一行 / 那一条标签上就出现，移开就没有。判定范围 = **整行 / 整条标签**
   （落在行末空白也算）。**悬浮与不悬浮两态都要画**（帧断言要两态都有）。
3. **列账**（照形态票的帧）：

   | 落点 | 标记落在第几列 | 占几列 | 标题起点 | 标题预算 | 位移 |
   | --- | --- | --- | --- | --- | --- |
   | 平铺格标题行 | 格内第 2 列 | 1 | 格内第 4 列 | 格宽 − 4 | 无 |
   | 顶部页签条标签 | 标签内第 2 列（`[` 之后） | 1 | 标签内第 4 列 | 24 | **无**（标签宽度不变 → 后面的标签与 `+N` 一字不差） |
   | 会话页行 · 宽档 | 行内第 1 列（**顶替标记列**） | 1 | 行内第 3 列 | 27 → 26 | 悬浮行标题右移 1 列 |
   | 会话页行 · 窄档 | 行内第 1 列 | 1 | 行内第 3 列 | 21 → 20 | 同上 |

4. **焦点标记全部退场**：平铺格标题行的 `◆`/`·`、页签条标签里的 `◆`、会话页行的前台标记 `▍` —— 三处
   都让位给关闭标记。**焦点（前台）改由 ACCENT + 粗体承担**（本界面已有的焦点语言）。
   —— **实现期澄清（2026-10-20，票 `05`）**：退场的是那三个**字形**；会话页里前台由**标题色
   `LIVE`** 那一档说（票 29 的三档标题色），**焦点行**由时间列 `ACCENT` + 粗体说。前台与焦点是
   **正交**的两件事（票 29 的注释明写「焦点是字重，不是颜色」），把前台也换成 `ACCENT` 会与焦点行
   的信号混在一处。代价：**无色终端**里前台认不出 —— 记在票 `05` 的落地注记里，票 `11` 的走查
   清单要带上。
5. **只在盘上、没装载的行不给标记**（那类行本来也关不掉）。
6. **会话页页顶那一行删掉 `关闭`**，只剩左端读数与右端 `新建`（空宿主时只剩 `新建`）。关闭点名那两档
   文案（`关闭「<标题>」`）随之退场。
7. **命中矩形必须先于**该行 / 该标签原有的命中动作注册 —— 命中表取**第一个**命中的区域，注册顺序即
   优先级；不先注册，点标记就永远是「落焦点 / 切前台」。三处各要一个**带会话身份**的命中动作
   （既有关闭动作硬编码焦点行）。
8. **点标记只关那一行**：不落焦点、不切前台。点行的其余部分仍是「落焦点」（`Enter` / 双击才切前台）。

### B. 悬浮目标与指针事件

9. **移动事件接进指针入口**：记下指针位置，用**当帧的命中表**翻译成**悬浮目标**（会话身份 / 页签序号 /
   格序号三样）。移动与「按住左键拖动」是两种事件，后者仍然是拖选，**不动悬浮**。
10. **谁算「相邻」**：**渲染器算**。它已经为了画页签条而持有宿主表顺序（标签就按那个顺序排），
    所以「下一个 / 上一个」对它现成；主循环只照做。
11. **点标记发什么**：若目标是**前台**那一会话，先发「切到相邻的那一个会话」再发「关掉目标」—— **两条请求、
    顺序固定**（先切后关）；若目标不是前台，只发「关掉目标」一条。
12. **渲染器不知道能不能关**：忙碌、没装载这两条判断在库层（关闭检查）与主循环，渲染器照发请求。
    —— **实现期澄清（2026-10-20，票 `06`）**：渲染层**另外**知道「在跑」（内存里的三态，票 22），
    于是它对**正在跑**的那一行**不先发切换** —— 切走了也关不掉，还把用户脚下的地板抽走；让库层
    拒它，提示行给一段可点的「切到「<它>」」（切过去好在那儿按 ctrl-c 取消）。

### C. 关闭动作的契约

13. **目标是「被点的那一会话」**，不再是焦点行。
14. **允许关前台**：关闭检查里那条「前台不许关自己」的拒绝**去掉**（含它的拒绝理由与文案）。
15. **关掉前台后，前台落到相邻的一个会话**：按宿主表顺序取**下一个**，没有就取**上一个**；都没有 → 既有的
    **空宿主态**（页签条空、输入区禁用、页顶读数 `0 个会话`）。
16. **平铺态同一套规则**：焦点格就是前台，关掉它之后焦点格落到**相邻格**；只剩一格时，既有行为就是
    自动回标签态。
17. **先切后关**：先改前台指针，再从宿主表里移除并结束那个会话的 task。理由：宿主表的关闭动作**只从
    表里移除、结束 task，不碰前台指针**，前台指针是独立的一个通道；先切后关不会出现「前台指针指向
    已移除的会话」的中间态。
18. **忙时仍拒绝**：那一会话正在跑回合时不给关。回执走**提示行两段** + 可点入口 —— 前半句说「那一会话正在
    跑 · 先取消」，后半句「切到「…」」整段可点（沿用既有关闭被拒的那条形状，只是换了前半句）。
19. **只读预览会话能关**（既有规则不变），它的关闭标记与普通行**同色**。
20. **其余既有规则一律沿用**：不二次确认、不写盘不删盘、可以关掉最后一个会话（进空宿主态）。

### D. 键位

21. **全局 `Ctrl-X`**：关掉**前台**那一会话（平铺态 = 焦点格）。任何界面都可用。
22. **会话页内 `x`**：关掉**焦点行**那一会话（与既有的 `r` 改名并列）。只在会话页有键盘时可用。
23. **输入区的 `Ctrl-W` 已被「删一个词」占用**，不重复占位；会话页的 `x` 是空位。
24. **任意键盘输入即清掉悬浮**（键入、翻页、任何键）—— 回到键盘工作时那个标记就该消失。
25. **空宿主态或没有焦点行时**，两条键位**不做任何事**（没有可关的对象），不提示。

### E. 字形与颜色

26. **字形 `✖`（U+2716，HEAVY MULTIPLICATION X）**：按 East Asian Width 它是 **Neutral → 恒 1 列**，
    CJK 字体下也不变。**不要用 `×`（U+00D7）** —— 那是 Ambiguous，在「ambiguous = wide」的终端里会变
    2 列，三处的列账各差 1 列。
27. **代码里不做双宽补偿**。若将来换成 Ambiguous 字形：标签宽 +1（后面标签右移、`+N` 变）、会话页行
    宽 +1（时间列末位被裁）、平铺格截断宽 −1 —— 三处预算都得各减 1 列，且要在真机上验。
28. **红色另立一个语义色**（例如「关闭」色，值 = 红）：它回答的是「这一下会毁掉东西」，与既有那个
    「错误」红（工具失败、会话错误）**撞值可以、名字不能混**。
29. **焦点靠 ACCENT + 粗体**：焦点标记退场后，前台会话在页签条与平铺格里的可辨性靠这两样。
    （会话页那一处走**标题色 `LIVE`** 那一档 —— 见上面第 4 条的实现期澄清。）

### F. 黏住与事件洪峰

30. **黏住怎么清**：**焦点事件**（终端的「焦点变化」模式，crossterm 的 `EnableFocusChange` /
    `FocusLost`）盖「切走窗口」；**任意键盘输入即清**盖「回到键盘工作」。**不选 hover 超时** ——
    超时是唯一能盖「鼠标移出窗口而终端仍聚焦」的手段（协议里没有该事件，kitty 的私有扩展会被 crossterm
    当解析错误丢弃），但它会让读标题时按钮闪。
31. **终端模式要成对撤销**：新加的那串焦点模式与既有的鼠标捕获、括号粘贴一样，在「进终端 / 退终端 /
    挂起恢复」三处成对开关（ADR 0002 的纪律）。
32. **事件洪峰怎么合并**：**只在悬浮目标变化时才置重画标记**。事件仍逐个进（移动与拖动在事件层已经
    分得开），但同一行内移动不重画 —— 一次横扫 80 列从约 80 帧降到 1～2 帧。
33. **拖选不碰关闭标记**：三处的标记都不落在标题字形上（会话页顶替标记列；页签条与格标题行在标题前
    留一列），拖选不会把它选进剪贴板 —— 仍要真机验一次。

### G. 术语与文档

34. **`CONTEXT.md` 新立两条词条**：**关闭按钮**（三处落点、悬浮才现、红 = 关闭色）、**悬浮目标**
    （指针当前落在哪一条会话上；移动事件，命中表翻译）。
35. **改既有词条**：**宿主表**（关闭 = 从表里移除；若它是前台，前台落到相邻；不再禁止关前台）、
    **前台**、**平铺** / **格** / **焦点格**（焦点标记退场）、**会话页**（页顶按钮删掉、每行带关闭标记）。
36. **`docs/render.md` 同步**：左栏一节、顶部页签条一节、平铺一节。
37. **`docs/tui-manual-checklist.md` 新增真机走查**（见下）。
38. **不立 ADR**：这几条决定改回去都是改绘制与契约代码、成本不高，没有一条够得上「难以逆转」。

## 测试决定

**什么是好测试**：只测**外部行为** —— 屏幕上长什么样、渲染器发出了哪条请求、库层允不允许。
不测实现细节（不测「有个叫 hover 的字段」、不测私有函数怎么算列号）。

### 接缝一：渲染器层（`TuiState` + 帧 + 指针 + 键位）

先例：`tests/render_layout.rs`（`draw_frame` 画一帧 → `TestBackend` 的缓冲 → `cells()` / `row_text()`
读回）、`tests/session_page.rs`（会话页的帧与页内键位）、`tests/render_tui.rs`。
指针事件用现成写法合成（`state.mouse(MouseEvent { kind, column, row })`），**补上移动事件**这一种。

覆盖：

1. **三处各两态**：悬浮时标记出现、不悬浮时没有（帧）。
2. **列账**：标记落在第几列、标题从第几列起、标题预算（宽档 / 窄档各一）。
3. **页签条不位移**：悬浮某个标签后，后面的标签起点与 `+N` 与不悬浮时一字不差（帧）。
4. **焦点标记退场**：帧里没有 `◆` / `·` / `▍`。
5. **页顶行没有 `关闭`**（帧）。
6. **未装载的行没有标记**（帧）。
7. **点标记关的是那一会话**：点第 3 行的标记 → 发出的是**那一行**的关闭请求（不是焦点行那一会话）。
8. **点前台那一会话的标记**：发出**两条**请求，顺序是「切到相邻」在前、「关掉目标」在后；相邻的那一个会话按
   宿主表顺序的下一个算，没有就取上一个。
9. **`Ctrl-X`**：发出前台那一会话的关闭请求；**会话页内 `x`**：发出焦点行那一会话的关闭请求。
10. **只关不切**：点标记不发「切前台」请求（目标非前台时只发一条）。
11. **空宿主 / 无焦点行**：两条键位都不发任何请求。
12. **洪峰合并**：同一行内连续多个移动事件**不产生多次重画**（比较重画标记的置位次数）。
13. **键盘清悬浮**：按任意键后重画一帧，标记消失。
14. **拖选不选进标记**：按住左键拖过标记所在的那一格，剪贴板内容里没有 `✖`。

### 接缝二：库层（关闭检查 + 宿主表）

先例：`tests/session_host.rs`（宿主表接缝：装载、切换、关闭、空宿主）。

覆盖：

1. **关前台不再被拒**（关闭检查）。
2. **忙时仍被拒**、**没装载仍被拒**（那两条拒绝的理由文案仍在）。
3. **只剩一个会话时可关**（既有例外）。
4. **关掉前台后前台落到相邻**：切到相邻再关掉目标之后，前台指针指向相邻的那一个会话；表里少了一行。
5. **只剩最后一个会话**：关掉之后宿主表为空（空宿主态的前置条件）。

### 真机走查（写进 `docs/tui-manual-checklist.md`）

1. 三处悬浮出标记、点它关掉**那一**场（不是焦点行那一会话）。
2. 关掉前台 → 前台落到相邻；平铺态关焦点格 → 焦点格落到相邻格。
3. 忙时点标记 → 提示行两段 + 可点的「切到「…」」。
4. `Ctrl-X` 与会话页 `x` 都能关掉目标。
5. 黏住：标记出现后切走窗口（焦点事件）或敲任意键 → 标记消失。
6. 一次横扫 80 列**不产生 80 帧**（数帧）。
7. **herdr 常态**：悬浮不出现（herdr 默认抓鼠标）—— 记一条。
8. 拖选**不**把标记选进剪贴板。

## 范围之外

- **hover 超时降级**（指针停着不动过一会儿就收起标记）：唯一能盖「鼠标移出窗口而终端仍聚焦」的手段，
  但会让读标题时按钮闪。
- **终端不报鼠标移动时的常显降级**：主流终端都支持「任何事件上报」，但 **herdr 默认自己抓鼠标**、
  GNU screen 最高只到「按下与滚轮」—— 那里悬浮不出现。**注**：两条新键位是独立入口，在这类终端里
  照样能关会话，只是按钮不出现。
- **撤销关闭 / 重开上一个会话**：关掉的那一会话盘上还在、可以再装载；「撤销」是另一件事。
- **组头行 / 右栏 / 详情浮层里的关闭标记**：本 spec 只管「会话名旁边」。
- **从盘上删掉一个会话**：现在「只在盘上、没装载」的行没有标记；将来若要做「删掉」，是另一件事。
- **快捷键面板、命令面板里加「关闭会话」条目**：本 spec 只给两条键位。
- **右键菜单、长按菜单、拖拽调整格边界**。
- **Web 界面的同一功能**：本 spec 只管 TUI。
- **改关闭语义之外的既有规则**：不二次确认、只读能关、关闭不写盘不删盘、关掉最后一个会话进空宿主态 ——
  一律沿用。

## 补充

- **三条已知代价**（知情接受）：① 悬浮那一行的**状态标记被顶掉**（在跑 / 等人类 / 前台）—— 而那正是
  决定「能不能点」的时刻（点下去还会被忙时拒绝挡回）；② **herdr 常态下悬浮不出现**；③ 窄档（28 列）
  的标题少 1 列。
- **与既有 spec 的关系**：本 spec **推翻** `session-tab` spec 的若干条款（见 H 节的表），实现时那几处要
  一并改写，别留两套说法。
- **细节去哪找**：列账与帧在[形态票](issues/02-prototype-close-button-shapes.md)；终端行为（谁报移动、
  密度、黏住、转发链）在[事实票](issues/01-research-mouse-move-events.md)；关闭契约、被推翻条款的逐条
  出处、实现落点清单在[决策票](issues/03-grilling-close-contract.md)。
- **实现者别凭印象重推**：这三条各自回答一件事（长什么样 / 终端给什么 / 关掉谁），三处都要照票做。
