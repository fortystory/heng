# 06: 关掉前台那一会话后，前台落到相邻

Type: implement
Status: ready-for-agent
Part of: ../map.md
Blocked by: 05

**要建的：** 前台那一会话也能直接关掉；关完之后前台**自动落到相邻的一个会话**（按宿主表顺序取下一个，
没有就取上一个），只剩一个会话时关掉进空宿主态。

## 验收

- [ ] 关闭检查**不再拒绝**关前台（那条拒绝理由与文案退场）；忙碌与没装载那两条拒绝仍在。
- [ ] 渲染器按宿主表顺序算「相邻」（下一个；没有就上一个），并在目标是前台时**先发切到相邻、
  再发关掉目标** —— 两条请求、顺序固定。
- [ ] 库层：先切再关之后，前台指针指向相邻的那一个会话，宿主表少一行。
- [ ] 关掉**最后一个会话** → 空宿主态（页签条空、输入区禁用、页顶读数 `0 个会话`）。
- [ ] 关掉**非前台**的那一会话 → 只发一条关闭请求，前台不动。
- [ ] 平铺态的焦点格（就是前台）被关掉时，焦点格落到相邻格；只剩一格时自动回标签态。
- [ ] 忙碌时点标记 → 提示行两段 + 可点的「切到「…」」（不再走「先切走再关」那句）。
- [ ] 两组测试：库层（关前台的落点、空宿主态）与渲染层（两条请求的顺序与目标 id）。
