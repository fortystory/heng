# 10: 黏住的标记会消失

Type: implement
Status: ready-for-agent
Part of: ../map.md
Blocked by: 04, 05

**要建的：** 指针移出终端窗口后，那个 `✖` 不会永远留在屏幕上 —— 切走窗口或敲任意键它就消失；
新加的终端模式与鼠标捕获、括号粘贴一样成对开关。

## 验收

- [ ] 终端的焦点变化事件到达 → 清掉悬浮目标并重画（标记消失）。
- [ ] 任意键盘输入 → 清掉悬浮目标。
- [ ] 新终端模式与既有的鼠标捕获、括号粘贴**成对开关**：进终端 / 退终端 / 挂起恢复三处都成对。
- [ ] 拖选**不**把 `✖` 选进剪贴板（三处的标记都不落在标题字形上）。
- [ ] **不引入 hover 超时**（标记不会自己闪掉）。
- [ ] 测试：焦点事件清悬浮、键盘清悬浮、拖选后的剪贴板里没有标记。
