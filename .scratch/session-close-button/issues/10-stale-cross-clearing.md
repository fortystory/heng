# 10: 黏住的标记会消失

Type: implement
Status: done
Part of: ../map.md
Blocked by: 04, 05

**要建的：** 指针移出终端窗口后，那个 `✖` 不会永远留在屏幕上 —— 切走窗口或敲任意键它就消失；
新加的终端模式与鼠标捕获、括号粘贴一样成对开关。

## 验收

- [x] 终端的焦点变化事件到达 → 清掉悬浮目标并重画（标记消失）。
- [x] 任意键盘输入 → 清掉悬浮目标。
- [x] 新终端模式与既有的鼠标捕获、括号粘贴**成对开关**：进终端 / 退终端 / 挂起恢复三处都成对。
- [x] 拖选**不**把 `✖` 选进剪贴板（三处的标记都不落在标题字形上）。
- [x] **不引入 hover 超时**（标记不会自己闪掉）。
- [x] 测试：焦点事件清悬浮、键盘清悬浮、拖选后的剪贴板里没有标记。

## 落地注记（2026-10-20）

- **终端模式 `?1004h`**（焦点变化报告）：加进 `enable_terminal_modes` 与 `disable_terminal_modes`
  —— **成对**（ADR 0002）。进终端、退出、挂起恢复三处都走这两个函数，所以三处都成对。不支持
  这一条的终端把它当没看见（private mode，终端自己会忽略）。
- **事件**：`CtEvent::FocusGained` / `FocusLost` → `TuiState::focus_changed()` → 清掉悬浮目标
  并重画。协议里**没有**「指针离开」这一种事件（票 01 的事实：谁会报、报多少），所以焦点变化
  是唯一能收到的信号。
- **任意键盘输入** → `TuiState::key()` 里清掉悬浮目标：敲了键就是有人在看屏幕，那个还挂着的
  `✖` 过期了。
- **不引入 hover 超时**：标记不会自己闪掉（决定票 03 里定的）。
- **拖选不把 `✖` 选进剪贴板**：那三处的标记都是**画上去的**（不在文本层里），拖选选不到它
  —— 这不是额外的规则，是「文本层只记可复制的字」这条既有纪律的结果。
- **测试**：[`tests/hover_clearing.rs`](../../../tests/hover_clearing.rs) 三条（焦点事件清悬浮、
  键盘清悬浮、拖选后的剪贴板里没有标记）。共用辅助里补了 `press` / `drag_to` / `release`。
