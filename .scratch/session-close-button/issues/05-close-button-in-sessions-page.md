# 05: 左栏「会话」页的关闭标记

Type: implement
Status: done
Part of: ../map.md
Blocked by: 04

**要建的：** 在左栏「会话」页，把指针移到某一行，那一行出现一个红色 `✖`；点它**关掉那一行**的会话
（非前台的也直接关），不动焦点。页顶那个 `关闭` 按钮随之删掉。

## 验收

- [x] 悬浮某行 → 该行第 1 列出现 `✖`（**顶替**状态标记位），标题从第 3 列起；宽档标题预算 27→26、
  窄档 21→20；时间列不动。
- [x] 指针移开 → 标记消失（悬浮与不悬浮两态各有一帧断言）。
- [x] **只在盘上、没装载**的行没有标记。
- [x] 点标记 → 发出的是**那一行**的关闭请求（不是焦点行那一会话），且**不**发出切前台请求、不改焦点行。
- [x] 会话页页顶那一行只剩读数与 `新建`；关闭点名那两档文案退场。
- [x] 只读预览会话（本来就能关）**有**标记，且与普通行同色。
- [x] 焦点标记（前台那一行的标记位）退场 —— 前台靠**标题色**认、焦点靠 ACCENT + 粗体认
  （**措辞澄清**见下面的落地注记）。
- [x] 命中矩形**先于**该行原有的命中动作注册（否则点标记会变成落焦点）。
- [x] 宽档与窄档各一帧断言；点标记发对会话 id。

## 落地注记（2026-10-20）

- **标记位顶替**：会话页的行第一列画 `✖`（`palette::CLOSE` = 红），**顶替**状态标记位；
  后面留一列，标题从第 3 列起、预算少一列（宽档 27→26、窄档 21→20），时间列不动。字形是
  `wording::CLOSE_CROSS`（U+2716，Neutral → 恒 1 列）。
- **只给关得掉的行**：那一行在**宿主表**里才给标记（`sessions.hosted`）—— 只在盘上的那几行
  关不掉，按钮不给。
- **命中**：新增 `HitAction::SessionCloseRow(usize)`（行号，与 `SessionRow` 同一条「存下标」的
  理由 —— `HitAction` 要保持 `Copy`）。它的矩形是行首那一格，**先于**整行注册：命中表取第一个
  命中的区域，注册顺序即优先级 —— 不先注册，点标记就变成「落焦点」。
- **页顶那个入口退场**：`HitAction::SessionClose` 变体与 `wording::SESSION_CLOSE`、
  `wording::session_close()`（`关闭「<标题>」`）一起删掉；页顶只剩读数与 `新建`。
- **措辞澄清（与决策票的一处出入，如实记）**：票面写「前台靠 ACCENT + 粗体认」，实现成
  **前台靠标题色 `LIVE`（绿）认、焦点行靠时间列 `ACCENT` + 粗体认**。理由：前台与焦点是
  **正交**的两件事（票 29 的注释明写），把前台也换成 `ACCENT` 会与焦点行的信号混在一处；
  退场的只是那个**字形** `▍`（它与三档标题色说的是同一件事）。`▍` 退场后前台仍由三档标题色
  里的 `LIVE` 那一档说得出。
- **一处已知代价（如实记）**：`▍` 退场后，**无色终端**里前台就只剩「标题色 `LIVE`」这一条
  通道 —— 颜色没有了，前台认不出（`▍` 本来是字形，无色也看得见）。这是形态票「焦点标记全退场」
  的后果，不是实现漏的。票 11 的走查清单要带上这一条（真机在无色终端里看一眼）。
- **交叉效果（票 07/08 也要知道）**：悬浮目标是**会话身份**，所以指针停在顶部页签条的某个标签
  上时，左栏会话页里**那一行**也会出现标记（那一场正被指着）。这是票 04 定下的语义，不是 bug。
- **关前台仍被库层拒**：这一票只保证「发出去的关闭请求指向被点的那一行」；「允许关前台」与
  「关完落到相邻」是票 06 的事。
- **审查里抓到的一处致命 bug**（已修）：`HitAction::SessionCloseRow` 没接进 `session_of_action`
  —— 命中表取**第一个**命中的区域，而标记那一格先注册，于是指针挪到 `✖` 上时悬浮目标变成
  `None`，下一帧不画标记、不注册矩形：**标记一点就消失、点不到**。现在整行与行首那个标记
  翻译成**同一行**，并且有一条测试专门把指针挪到标记那一格上（`the_close_mark_itself_stays_hovered`）。
- **测试**：[`tests/session_close_button.rs`](../../../tests/session_close_button.rs) 十四条（悬浮
  出标记、窄档也出、指针移开就消失、没装载的行没有、只读会话也有、点标记关的是那一行且不切
  前台不改焦点、页顶没有关闭入口、前台字形退场）。渲染器测试的共用辅助抽到了
  [`tests/common/mod.rs`](../../../tests/common/mod.rs)（`tests/session_page.rs` 与
  `tests/pointer_hover.rs` 也改用它）。`tests/render_layout.rs` 里还有一份自己的重复辅助 ——
  收拢它是一次独立的整理，开成票 [`12`](../issues/12-test-helpers-into-common.md)。
- **既有测试跟着改**：删掉「页顶那个入口点名要关的是哪一个」那条（功能退场）；窄档页顶改成
  「只剩 `新建`」；「前台那个字形」改成读**标题色**；`tests/render_layout.rs` 里那条靠
  「页顶含『关闭』」把页顶行滤掉的断言改成按读数行滤（页顶不再有 `关闭`）。另清掉四处退场
  残留：`src/session/listing.rs` 里「它自己带 `▍`」那句、`src/render/tui.rs` 里「页顶那两个
  入口」两句、`tests/session_page.rs` 里按「`关闭「`」滤页顶行」那句。
