# 05: 左栏「会话」页的关闭标记

Type: implement
Status: ready-for-agent
Part of: ../map.md
Blocked by: 04

**要建的：** 在左栏「会话」页，把指针移到某一行，那一行出现一个红色 `✖`；点它**关掉那一行**的会话
（非前台的也直接关），不动焦点。页顶那个 `关闭` 按钮随之删掉。

## 验收

- [ ] 悬浮某行 → 该行第 1 列出现 `✖`（**顶替**状态标记位），标题从第 3 列起；宽档标题预算 27→26、
  窄档 21→20；时间列不动。
- [ ] 指针移开 → 标记消失（悬浮与不悬浮两态各有一帧断言）。
- [ ] **只在盘上、没装载**的行没有标记。
- [ ] 点标记 → 发出的是**那一行**的关闭请求（不是焦点行那一会话），且**不**发出切前台请求、不改焦点行。
- [ ] 会话页页顶那一行只剩读数与 `新建`；关闭点名那两档文案退场。
- [ ] 只读预览会话（本来就能关）**有**标记，且与普通行同色。
- [ ] 焦点标记（前台那一行的标记位）退场 —— 前台靠 ACCENT + 粗体认。
- [ ] 命中矩形**先于**该行原有的命中动作注册（否则点标记会变成落焦点）。
- [ ] 宽档与窄档各一帧断言；点标记发对会话 id。
