# 09: 两条键位：全局 Ctrl-X 与会话页内 x

Type: implement
Status: ready-for-agent
Part of: ../map.md
Blocked by: 06

**要建的：** 纯键盘也能关会话 —— 任何界面按 `Ctrl-X` 关掉前台那一会话；左栏「会话」页里按 `x` 关掉
焦点行那一会话。

## 验收

- [ ] `Ctrl-X` 发出前台那一会话的关闭请求；目标忙碌时走与点标记同一条拒绝路径。
- [ ] 会话页内 `x` 发出**焦点行**那一会话的关闭请求（键盘路径作用于焦点行，不是「被点的行」）。
- [ ] 空宿主时 `Ctrl-X`、无焦点行时 `x`：**不做事、不提示**。
- [ ] 输入区的 `Ctrl-W`（删一个词）不受影响；`x` 不与既有的 `r`（改名）冲突。
- [ ] 两条键位写进页内键位提示与文档。
- [ ] 键位测试：两条键各自发出对的目标；无目标时不发任何请求。
