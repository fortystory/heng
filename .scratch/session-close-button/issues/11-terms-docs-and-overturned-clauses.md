## 落地注记（2026-10-20）

- **`CONTEXT.md` 新立两条词条**：**关闭按钮**（三处落点、悬浮才现、红 = 关闭色）、**悬浮目标**
  （指针当前落在哪一条会话上；代码里那个字段叫 `hover`、只读口叫 `hovered_session()`，词条与代码
  用同一个词）。**改既有词条**：**前台**（关掉它时落到相邻）、**宿主表**（关闭 = 从表里移除；若
  它是前台，前台落到相邻；不再禁止关前台）、**空宿主**（前台指针仍指着那个刚被关掉的会话 ——
  关闭不碰指针）、**顶部页签条**（`[✖ 标题]` / `[ 标题]`，哪一签是前台只靠 ACCENT + 粗体）、
  **平铺**（关掉一个之后只剩一个 → 自动回标签态）、**格**与**焦点格**（焦点标记退场）、**会话页**
  （页顶只剩 `新建`、每行带关闭标记、标记列那一枚 `▍` 退场）、**语义色板**（加「关闭」红）。
- **一处体量细节**：**语义色板**那个词条本来就快到 500 字符（`check-doc-size.py` 的「单元 ≤500」）
  —— 「关闭」那一句因此**单独成段**，不与前一句挤在一段里。
- **`docs/render.md`**：左栏（会话页那节：页顶只剩 `新建`、标记列、关闭标记、两条键位）、顶部页签条
  （`[✖ 标题]`、焦点靠 ACCENT + 粗体、点标记关那一个）、平铺（格标题行上的关闭标记、焦点标记退场）
  三节同步。
- **`session-tab` spec 十二处逐条改写**：页顶 `关闭` 入口、前台不许关自己、关闭点名、只走鼠标、
  两步关闭、页内键位表（页内不新增 `Ctrl-*`，但**全局**那条 `Ctrl-X` 不属于页内）、三处焦点标记、
  关闭动作硬编码焦点行、视图重建触发点、宿主表词条、docs 描述。
- **走查清单**新增一节 `㊺`（八条，含 **herdr 常态**那一条：终端复用器下移动事件照常、焦点变化
  多半不来，于是那个 `✖` 会一直挂着直到下一次移动或按键）。
- **不立 ADR**：这一轮没有不可逆的决定 —— 三处落点的形状、两条键位、黏住的清法都在 spec 与决策票
  里说完了。
