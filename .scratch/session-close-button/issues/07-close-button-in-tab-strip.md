# 07: 顶部页签条的关闭标记

Type: implement
Status: ready-for-agent
Part of: ../map.md
Blocked by: 05

**要建的：** 标签态下，把指针移到顶部页签条的某个标签上，那个标签出现一个红色 `✖`；点它关掉
那一会话。

## 验收

- [ ] 悬浮某标签 → 标签内第 2 列（`[` 之后）出现 `✖`，标题从第 4 列起、预算 24 **不变**。
- [ ] **标签宽度不变** → 后面的标签起点与 `+N` 与不悬浮时一字不差（零抖动）。
- [ ] 点标记 → 发出那一会话的关闭请求（不是焦点标签那一会话）；目标是前台时按
  [06 关掉前台那一会话后，前台落到相邻](06-close-foreground-and-land-on-neighbor.md) 的规则先切后关。
- [ ] 焦点标记 `◆` 退场 —— 哪一签是前台只靠 ACCENT + 粗体认。
- [ ] 标签多到收成 `+N` 的那一档同样成立（`+N` 仍不可点）。
- [ ] 悬浮与不悬浮两态各一帧断言；点标记发对会话 id。
