# 07: 顶部页签条的关闭标记

Type: implement
Status: done
Part of: ../map.md
Blocked by: 05

**要建的：** 标签态下，把指针移到顶部页签条的某个标签上，那个标签出现一个红色 `✖`；点它关掉
那一会话。

## 验收

- [x] 悬浮某标签 → 标签内第 2 列（`[` 之后）出现 `✖`，标题从第 4 列起、预算 24 **不变**。
- [x] **标签宽度不变** → 后面的标签起点与 `+N` 与不悬浮时一字不差（零抖动）。
- [x] 点标记 → 发出那一会话的关闭请求（不是焦点标签那一会话）；目标是前台时按
  [06 关掉前台那一会话后，前台落到相邻](06-close-foreground-and-land-on-neighbor.md) 的规则先切后关。
- [x] 焦点标记 `◆` 退场 —— 哪一签是前台只靠 ACCENT + 粗体认。
- [x] 标签多到收成 `+N` 的那一档同样成立（`+N` 仍不可点）。
- [x] 悬浮与不悬浮两态各一帧断言；点标记发对会话 id。

## 落地注记（2026-10-20）

- **标签形如 `[✖ 标题]` / `[ 标题]`**（`wording::top_tab`）：标记位是**关闭标记**（指针悬着时
  红 `✖`）或一格空气 —— 焦点那枚 `◆` 退场，哪一签是前台只靠 **ACCENT + 粗体**认（既有样式）。
  `✖` 是 U+2716（Neutral → 恒 1 列），`◆` 与空格也是 1 列 → **标签宽度不变**，后面的标签起点
  与 `+N` 一个像素都不动（零抖动）。
- **标记要自己的颜色**：整条标签是一个 span（前台那签是 ACCENT + 粗体），所以那个 `✖` 是**单独
  画**在标记位上的（`palette::CLOSE` 的红）。
- **命中**：新增 `HitAction::TopSessionClose(usize)`（宿主表下标，与 `TopSession` 同一条「存下标」
  的理由）。它的矩形是标记位那一格，**先于**整条标签注册 —— 命中表取第一个命中的区域，注册
  顺序即优先级（不先注册，点标记就变成「切前台」）。
- **点标记**走 `TuiState::close_session`（票 06 的那一条）：目标是前台时**先切到相邻、再关**。
- **`+N` 仍不可点**：它不进命中表（既有）。
- **测试**：[`tests/close_mark_sites.rs`](../../../tests/close_mark_sites.rs) 五条（悬出标记且是红
  的、零抖动、点标记关那一个、点前台那一个先切再关、焦点那签是 ACCENT + 粗体）+ `+N` 不可点一条。
- **既有测试跟着改**：`tests/render_layout.rs` 的「顶部条在主列里」那条原本断言有 `◆` → 改成断言
  没有、且前台那签靠 ACCENT + 粗体。
