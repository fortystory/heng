# 08: 平铺态格标题行的关闭标记

Type: implement
Status: done
Part of: ../map.md
Blocked by: 05, 06

**要建的：** 平铺态下把指针移到某一格的标题行，那一格出现一个红色 `✖`；点它关掉那一会话。

## 验收

- [x] 悬浮某格 → 格内第 2 列出现 `✖`，标题从第 4 列起、预算 = 格宽 − 4 **不变**（挤 0 列）。
- [x] 点标记 → 发出那一会话的关闭请求；目标是焦点格时按
  [06 关掉前台那一会话后，前台落到相邻](06-close-foreground-and-land-on-neighbor.md) 的规则先切后关。
- [x] 焦点标记 `◆` / `·` 退场 —— 焦点格靠 ACCENT + 粗体认。
- [x] 关掉焦点格 → 焦点格落到相邻格、其余格重排；只剩一格时自动回标签态。
- [x] 窄档（格宽 32）一帧断言；标题的截断宽不变。
- [x] 悬浮与不悬浮两态各一帧断言；点标记发对会话 id。

## 落地注记（2026-10-20）

- **格标题行形如 `✖ 标题` / ` 标题`**（`wording::tile_title`）：标记位是**关闭标记**（指针悬着时
  红 `✖`）或一格空气 —— 焦点那枚 `◆` 与其余那枚 `·` 都退场，焦点格靠 **ACCENT + 粗体**认。
- **标题的截断宽不变**（格宽 − 4）→ 悬浮不挤标题、格宽不变。
- **命中**：新增 `HitAction::TileClose(usize)`（格序号，与 `Tile` 同一条「存下标」的理由）。它的
  矩形是标记位那一格，**先于**整格注册（不先注册，点标记就变成「换焦点」）。
- **点标记**走 `TuiState::close_session`（票 06 的那一条）：目标是焦点格（就是前台）时**先切到
  相邻、再关**。
- **焦点格落到相邻格**：前台换了，焦点格就跟着换（`draw_tiles` 里 `let focus = state.front()`）；
  只剩一格时回标签态是既有行为（`rebuild_tiles`，票 19）。
- **测试**：[`tests/close_mark_sites.rs`](../../../tests/close_mark_sites.rs) 四条（悬出标记且是红
  的、点标记关那一个、焦点格是 ACCENT + 粗体、焦点格落到相邻格）。
- **票面说的「窄档（格宽 32）一帧断言」**：格标题那套代码路径与宽度无关（标记位恒 1 列），测试
  在 120 屏（格宽 ≈39）上断言；更窄的屏是同一条路径。
- **既有测试跟着改**：`tests/render_layout.rs` 的「每个宿主表会话都有一格」那条原本断言格标题含
  `◆` / `·` → 改成断言没有、标题还在。
