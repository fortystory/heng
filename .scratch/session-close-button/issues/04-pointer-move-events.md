# 04: 指针的移动事件不再被丢掉

Type: implement
Status: ready-for-agent
Part of: ../map.md
Blocked by: —

**要建的：** 终端上报的鼠标移动事件不再被渲染器丢掉 —— 渲染器知道指针此刻停在**哪一条会话**上
（**悬浮目标**），并且**只在悬浮目标变化时**才请求重画：鼠标在同一行里划过不刷屏。

## 验收

- [ ] 指针的移动事件进到渲染器的指针入口，不再落进兜底分支被丢弃；渲染器记下指针位置。
- [ ] 渲染器能把指针位置翻译成**悬浮目标**（哪一个会话：会话页的行 / 页签条的标签 / 平铺的格）。
- [ ] 同一行内连续移动**不产生多次重画**（悬浮目标不变 → 不请求重画）。
- [ ] 指针不在任何会话上时没有悬浮目标。
- [ ] 按住左键拖动仍然是拖选，**不改变**悬浮目标。
- [ ] 现有的点击、滚轮、拖选、复制行为一个字不变（回归）。
- [ ] 两条测试：悬浮目标随指针移动而变；同行内移动不触发重画。

## 依赖

无（可以立刻开工）。决定见 [`../spec.md`](../spec.md) 的「B 悬浮目标与指针事件」与
[关闭这条动作的契约改写](03-grilling-close-contract.md)（洪峰合并那条）。
