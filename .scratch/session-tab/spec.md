## 问题陈述

1. **一个进程只能有一个会话。** `Harness` 绑着 cwd、沙箱探测、权限策略、技能、工具表
   （`src/lib.rs:207-228`），渲染器一进程一个、绝不重建（`src/lib.rs:155-157`）。于是「同时开两个」
   只能开两个终端、两套进程。
2. **切会话要先退出再进来。** 唯一的跨会话动作是 CLI 的 `-c <id>`（`src/cli.rs:176-193`）；
   在会话中途想看另一个会话，只能退出。
3. **盘上的历史找不到。** 会话按 cwd 的桶散在 store 里（281 个会话 / 74,803 事件，实测），
   `heng sessions ls` 是另一个进程里的 CLI；界面里没有任何入口。
4. **切走 = 丢掉现场。** 没有「切走但留着」这回事，正在跑的回合也一样。
5. **后台有事没人知道。** 人在别的窗口干活时，本进程里有没有会话在等人答、有没有回合刚跑完，
   终端标题只认当前那个会话。

## 解决方案

左栏加**第五签 `会话`**，放在页签条**最前**：它列 store 里跑过的全部会话，按检出分组，
一行 = 状态标记 + 标题 + 右对齐相对时间；点一条即切过去。

- **多会话宿主**：一个会话 = 一个 `Harness` + 一个拥有它的 tokio task；主循环持一张**宿主表**，
  前台指针是全进程一个 `watch<SessionId>`。切走的后台会话**继续跑回合、不卸载**。
- **页顶一行**：并发读数 `已装载 N 个 · M 个在跑` + 右端 `新建` / `关闭`；页内键盘（`↑`/`↓`、`Enter`、
  `r`、`/`、`Esc`）；不滚动、末行 `＋N 个会话`；三级降级阶梯。
- **新建** = 同 cwd 再加载一个**空**会话、立即成为前台，旧的留在宿主表里；**关闭** = 从宿主表移除，
  盘上目录留着、随时能再装载。
- **空宿主态**：关掉最后一个之后没有前台，会话页页顶 `0 个会话` + 只剩 `新建`，页区 `没有会话`，
  输入区禁用。
- **后台信号**：终端标题的**状态段**认「后台有待答 / 后台刚跑完」——`N 个待答` / `N 个跑完`。

## 实现决定

### §1 宿主与所有权（票 04）

- **一个会话 = 一个 `Harness` + 一个拥有它的 tokio task**；`Harness` 就是宿主，**不造新词**。
- 新增**宿主表**（主循环持有，位于 CLI 组装点之上）：每行 = `id` / `cwd` /
  `state: watch::Receiver<SessionState>` / `cmd: mpsc::Sender<SessionCommand>` /
  `cancel: CancelSignal` / `join: JoinHandle<()>`；表级一个 `foreground: watch::Sender<SessionId>`。
- **前台指针 = 全进程一个 `watch<SessionId>`**；切换只是改它，**忙闲不阻挡**（目标正在跑回合也照样切）。
- 命令只有三个：`Submit` / `Cancel` / `Close`。状态三态 `Idle` / `RunningTurn` / `AwaitingHuman`，
  用 `watch`（保最新不丢）；每个状态变更点另往渲染通道发一条带 session id 的状态事件。
- **同一个 `SessionId` 在表里只能有一行**；`Harness` 要满足 `Send`（要被 `tokio::spawn` 接受）。
- `render` / `render_task` 从 `OpenedSession` 抽成**进程级一份**；`PathLocks` 升成进程级
  `cwd → 表`（键是规范化 cwd）；**不设并发上限**，界面只给读数。
- 手势归属：会话级 `/model`、`/effort`、`Shift+Tab`、`/clear` 落前台；进程级 `Ctrl-O`、宽度档、
  终端标题全局。`Ctrl-C` **只取消前台当前动作、永不退出**；`Ctrl-D` 退出，**有任何回合在跑就拒绝**
  并给一个可点入口指向在跑集合的第一个会话。

### §2 装载与切入（票 05）

- **一条共用的装载函数**（`-c <id>` 与界面点选同一条路径）：先做能立即判定的检查
  （已是前台 / cwd 目录不存在 / 流损坏），通过后交给装载 task，装完再切前台。
- 新事件 **`SessionFactsChanged`**（会话事实的**全量快照**，log-only），**当前事实 = 流上最后一条**；
  `SessionStarted` 补 model / provider / effort / permission_mode / sandbox_mode 五个 `Option` 字段
  （**不记** context_window 与沙箱可用性）；每个 `Option` 加 `serde(default)`。
- **`SCHEMA_VERSION` 2 → 3**（与票 01 的 `SessionTitled` 同一次涨版）。
- 旧流缺字段 → 回退**进程配置默认**并如实说明（提示行一条 + 常驻标记，合并成一句）。
- 每次装载后补一条完整快照；环境类事实（沙箱 / 技能 / `AGENTS.md`）**重探**。
- **只读预览**：装不成可写会话（cwd 不存在 / 坏流半读）时的降级落点；**凡写流的一律禁**
  （提交、所有 `/` 命令、`Shift+Tab`、页内改名、新建），宿主表加只读标志而不动三态。
  损坏流三档：尾行坏 → 可写、半读 → 只读、读不出 → 拒装。
- **装载收成一个动作**（票 [33](issues/33-attach-cwd-single-source.md) / [34](issues/34-attach-one-action.md)，
  2026-10-12 一轮架构访谈定）：cwd 只有一个来源（流上的 `SessionStarted.cwd`，读不出即**拒装**）；
  装配、入表、接应答者、切前台与「装完要说的几句」收进 `cli.rs` 的 `mod loading`，`rollover` 的交接
  仍留在新建那一层薄壳里。本节第一条的「一条共用的装载函数」到此才算走完 —— 此前共用只到
  `load(AssemblyParts)` 为止。

### §3 会话页的形态（票 02 / 06）

- **第五签 `会话` 放最前**：`会话┆调用量┆todo┆文件┆改动`。窄档 28 列五签占 **26 列**，余 2 列 `┄`。
  页签**常驻**（空 store、读不出、无 `git` 时都在）。
- **行 = 标记列 1 + 标题 T + 间隔 1 + 时间 Tw**：窄档 `T=21, Tw=5`（`刚刚` / `3分` / `2时` /
  `昨天` / `08-12`）；宽档 `T=27, Tw=11`（`刚刚` / `3 分钟前` / `2 小时前` / `昨天 14:02` /
  `08-12 14:02`）。标题走 `text_columns` + 尾 `…`，不按字节。
- **状态标记**（只用现成界面域色）：前台 `▍`+`ACCENT`（不加 `BOLD`）、待答 `?`+`WARN`、
  后台活跃 `●`+`PLAIN`、空闲留空、cwd 不存在整行 + 组头 `MUTED`、流损坏尾 `损坏`+`BAD`
  **排在时间之前**（原写「之后」会顶出栏宽）。四态互斥；后两者可与任意态共存。
- **焦点行 = `ACCENT` + `BOLD` 整行**（与 `文件` / `改动` 同档）。
- **分组 = 按 cwd**：家族探测成功（`rev-parse --path-format=absolute --git-common-dir`）→ 组头 =
  `--show-toplevel` 目录名；失败 → 按 cwd 字符串各成一组、组头 = 目录名；重名写尾两段路径。
  组头占整行、不带计数与分支名、**不给命中动作**、空组不画。
- **排序**：前台所在的检出组钉组顶 → 组间 / 组内 mtime 降序 → id 降序兜底 → 读不出 mtime 的排最后。
- **页顶一行**：左端读数 `已装载 N 个 · M 个在跑`（`MUTED`），右端 `新建` + `关闭`（都 `ACCENT`、可点），
  `关闭` 作用于焦点行。**空宿主时**这一行是 `0 个会话`、右端只剩 `新建`。
- **不滚动**：末行 `＋N 个会话`（`MUTED`），`N` = 一条都没露过面的会话数；前台永远可见
  （它在钉顶那组的第一行），**过滤态下这条让位**。
- **三级降级阶梯**：页区 ≥8 行 = 组头 + 读数行；6–7 行 = 丢组头（平铺）、保读数行；
  <6 行 = 组头与读数行都不画，只保列表与 `＋N 个会话`。
- **页内键盘**（点左栏任意处交键盘）：`↑`/`↓` 移焦点（跳过组头）· `Enter` 切过去 · `r` 改名
  （复用常驻 `editor`）· `/` 进过滤 · `Esc` 一层层退（过滤 → 还键盘）。**不新增 `Ctrl-*`**。
- **点击行为**：单击任一行 = 交键盘 + 落焦点 + 能切就立刻切；点前台那一行只做前两步；
  cwd 不存在 / 流损坏两行不切、焦点照落、各回一句提示行。
- **过滤**（票 10）：页内 `/` 进，**过滤态整行占用页顶那一行**（左端 `会话` + 查询串、右端
  `n 个命中`）；判据 = **标题 + 组头目录名**、空格分词、大小写不敏感、各词 AND，**只在前缀轻路径
  已派生的列表上筛**；结果 = 只剩命中行 + 组头保留 + 空组不画；`Enter` = 接受并离开过滤；
  `Esc` 输入态 = 取消这次过滤（还原草稿）、已生效态 = 清过滤；过滤态**进程级**。
- **页区文案**（措辞层，不许散进渲染代码）：`还没有历史会话`（store 空）、`读不出会话列表`
  （store 读不出）、`没有会话`（空宿主）、`没有命中的会话`（过滤空结果）。**无 `git` 不产生文案**。

### §4 数据来源：前缀轻路径（票 01 / 02 / 03）

- 列表与标题派生**绝不走 `observe::summarize`**（全量解析，281 个会话实测 155.6–172.2 ms）。
  走：`list_all`（4.6–5.1 ms）+ 逐条 `metadata().modified()` + **前 8 行前缀读**（3.7–4.8 ms），
  整轮约 10 ms；只要 `SessionStarted.cwd` 与首条 `role: User` 消息的 `text`。
- **标题权威链**：最后一条非空 `SessionTitled` → 前 8 行内首条用户消息首行 → `MM-DD HH:mm` 兜底。
  派生结果**不落流**、按票 01 §4 只放进程内缓存。
- **`SessionTitled { title }`**：log-only、按散文打码、**空串即撤回**；改名入口 = 页内单键（`r`）
  与 CLI `heng sessions title <id> <text>`。
- **绝不走 `EventLog::open`**（它会补换行 / 截断坏尾巴，**改文件**）：列表与派生都是只读动作。
- 一条坏流**不毁整页**（`list_all` 只扫目录），只体现在那一行的「流损坏」标记上。

### §5 新建与关闭（票 07）

- **新建** = `SessionStore::create` + 组装点建 log + `record_skeleton` 写 `SessionStarted`；
  cwd = 当前前台的 cwd（空宿主时 = 进程启动 cwd）；**完成后立即成为前台**。
- **继承规则**：模型 / effort / 权限模式**继承前台**；沙箱档、技能、`agents_md`、工具表按同 cwd
  重探或重取；`carried_tokens` 清 0。
- **`/clear` = 阈值 rollover = 页签新建**：同一个动作，旧的留在宿主表里可切回、**不写收尾事件**。
  取消 `/loop` 闸门（`clear_while_looping`）：旧会话连它在跑的 loop 一起留后台。
- **关闭** = 从宿主表移除（发 `Close` → await `JoinHandle`），**不写盘不删盘**：
  焦点行是前台时**禁止**（回执「先切到别的会话再关」）；那个会话正在跑回合时**拒绝**
  （回执「先在那个会话按 ctrl-c 取消」）；空闲会话**单击即关、不二次确认**；**只读预览会话能关**。
- **可以关掉最后一个会话** → **空宿主态**：页顶 `0 个会话` + 只剩 `新建`，页区 `没有会话`，输入区禁用、
  提交时提示行回 `没有会话，先新建一个会话`。
- **退出**：过闸门后广播 `Close` → await 全部；**不写收尾事件**；过了在跑的闸门之后，若后台还有
  空闲会话，提示行补一句 `还有 N 个后台会话`。**下次启动不自动加载**上次的宿主集合。

### §6 视图重建（票 08）

- **单份投影 + 切回按事件流快照全量重建**：渲染器只持一份会话投影；切回时按目标会话的
  **事件流快照**整批重放。否掉「每会话一份活投影」（后台不送事件，与票 04 §4 冲突、内存 ×N），
  也否掉 LRU 缓存。
- **投影收成一个子结构**，切换 = `self.view = View::new(facts)` **整块换**；进程级字段
  （`tab` / 主列页 / `Ctrl-O` 意愿 / 举手槽 / 脉冲 / 宽度档）留在本体。**不写 reset 清单**：
  `TuiState` 98 个字段里有 10 个投影字段根本没有清空入口（`transcript` 无 `clear`、`painted` 用
  `mem::take` 保内容、`timeline` 只增不减、`block_at` 以 `BlockId` 为键…）。
- **`SessionFacts` 与配色整份换**（它们在构造时注入、`apply` 不碰），否则切到 B 后状态行还写着 A。
- **会话级轻状态另存一张表**（键 = `SessionId`）：草稿、两个 `Pane` 的视口意图、转录滚动位置与
  「跟随末尾」、浮层（详情 / 文件查看器 / picker / `/` 菜单 / 轨迹搜索与折叠）。切换 = 先收走
  当前那份、再装入目标那份。**页签选择与页内焦点是进程级**（不在这张表里）；
  **会话页的过滤态也是进程级**。
- **控制通道**：复用 `ConsoleRequest`，加一个变体 `SwitchSession { facts, events }`；
  **启动那条 `Replay` 被收编成同一个机制的特例**（`TuiOptions.reopened` 门闩被吸收）。
- **补齐不重不漏**：以快照最大 `seq` 记作 `S`；重建期间目标会话的 `Logged` **全部进 `live_buffer`**
  （要改现状：现在重放时**丢弃一切 `Logged`**）；收尾只 apply `seq > S`。`RenderEvent` 按票 04 §4
  打 session id，渲染器**只 apply 当前前台的 `Logged`**。
- **在飞的旧重建先收尾**（插分隔行 + 排空 `live_buffer`）再开新的；**复用重放视觉但不插**
  「以下是历史」分隔行。**重建必须走 `apply`**（`links` / `thinking_*` / `colors` / 命中索引 /
  `painted` / `block_at` / `timeline` / `panel` / `todo` / `turn_*` 都是它的副作用）。
- **触发点**：点击行 / 新建后切过去 → 一条 `SwitchSession`；关闭**非前台**会话 → 只重画会话页 +
  删轻状态表那一行；关闭前台 → 禁止；空宿主 → 前台置空。
- **不变量**：已在宿主表里的会话**绝不重走 `assemble`**（否则 `resuming` 闸门会把进行中的工具调用
  读成崩溃遗留、合成一条「结果未知」）。

### §7 后台通知（票 11）

- **认，且放进终端标题的「状态段」**（段数不变、丢序表不动 —— 于是待答信息最后才被丢）。
  状态段取值优先级：后台待答 `N 个待答` → 前台重放 `重放中` → 前台待答 `等你` →
  后台未读的刚跑完 `N 个跑完` → 前台在跑 `运行中` → 空（省略整段）。
- **N 只算后台**：前台自己的待答沿用 `等你`、前台在跑沿用 `运行中` —— **单会话行为一字不变**。
- **「跑完」这条边沿在消费侧从电平快照推**：宿主表每个的 `watch` 保最新不丢，主循环每帧与上一帧
  比对推出 `RunningTurn → Idle`；**不新增通道**（一帧内翻两次会漏，可接受）。
- **未读的寿命** = 用户下一次键盘 / 鼠标输入，或那个会话又开跑；未读集合住**主循环**，
  「已读」由渲染器经既有的上游手势队列回报。
- **不需要额外节流**：标题只在真变了才写 OSC（既有的快照比对）。

### §8 `/clear`、收尾判定与标题（票 01 / 07 / 11）

- **`SessionEnded` 不新增写入点**（现状零写入点、0/281 条流以它结尾）：关闭与退出**不写收尾**，
  既有判定（goals 的收尾事件 + pending 工具调用配对 + 「流里有没有 `SessionStarted`」）全部照旧。
- **`sessions ls` / `sessions stats` 的末列改按末条事件派生**（替换现在读 `SessionEnded` 那一支）：
  末条是 `TurnEnded` / `RoundEnded` / `GoalCompleted` / `GoalStopped` → `停稳`；末条是缺配对的
  `ToolCallStarted` → `中断`；其余（含只有 `SessionStarted` 的空会话）→ `未收尾`。纯派生、不加字段。
- **终端标题**（票 01）：四段 `<路径> · <标题> · <状态> · <目标名>`（现状是三段，加标题段是本图
  的动作），丢序 = 目标名 → 标题 → 状态词 → 路径退基名 → 硬截断 40 列。
- `/clear` 的回执文案改成「新开一个，旧会话留在列表里」的口径。

## 测试决定

**好测试的样子**：只测**外部行为** —— 一个帧里画了什么、一个键产生什么状态转换、一次切换之后
屏幕与列表是什么样；不测私有字段、不测内部函数调用序列。时序性的东西（脉冲、重建分批）用显式的
步进来驱动，不用 sleep。

**三个 seam（两个复用、一个新增）**：

1. **`TuiState` 的帧与键位接缝（复用）**：照 `tests/render_layout.rs` 的 `framed()` / `screen_text()`
   助手，把 `TuiState` 渲进固定尺寸 `TestBackend` 后断言字符格；键位直接调状态机的 `key`。
   覆盖：页签次序与列宽、行格式与截断、四种标记与颜色角色、组头与空组、`＋N 个会话`、三级降级、
   页顶行 / 过滤行 / 空宿主态、过滤判据与空结果、焦点保位。
2. **`ConsoleRequest` 注入接缝（复用）**：照 `tests/history_replay.rs` 直接
   `state.request(ConsoleRequest::Replay { events })`（新变体同理），用循环调用的同一个
   `replay_batch` 步进。覆盖：切换重建、`seq` 去重补齐、在飞重建先收尾、投影整块换后不留上一个会话的
   状态、终端标题状态段的取值表。
3. **宿主组装接缝（新增，最高层）**：一个进程内的「宿主表 + N 个会话」构造入口（假 provider，
   照 `tests/goal_loop.rs` 用 `Harness` 的先例）。覆盖：新建 / 切前台 / 切走不卸载 / 后台继续跑 /
   关闭的四条规则 / 三态流转 / 待答挂住与切过去弹出 / 退出闸门 / 未读边沿与已读清除。

**prior art**：`tests/render_layout.rs`（帧断言与左栏几何）、`tests/history_replay.rs`（重放接缝）、
`tests/goal_loop.rs`（`Harness` 级行为）、`tests/todo.rs` 与 `tests/render_changes.rs`（左栏页的
行为测试）、`tests/observe_cli.rs`（`sessions ls` 的输出断言，末列三档改这里）。

## 进一步说明

- **已知代价（有意接受）**：列表范围是 store 里的**全部**会话（放宽后 281 个会话），`＋N 个会话` 会遮掉
  大部分 —— 可达性交给过滤（票 10）。行序会随 mtime 漂移，两次重扫之间可能变。检出显示名可能
  重名，已用尾两段路径兜。家族探测每 cwd 起一次 `git` 进程。
- **不设并发上限**：一个会话一个 task，开几个是人的手势；界面只给「几个在跑」的读数。防烧钱仍靠每个
  自己的额度闸门。
- **只读预览的边界**：它不是新的装载目标，只是降级落点；宿主表里只是一个只读标志，三态不动，
  退出闸门也不算它在跑。
- **长会话切换的延迟要在实现期实测**：单个会话的事件数中位数 9、p90 623、最大 14,544；常见切换是瞬时的，
  长尾那几个按启动重放的密度外推是百毫秒到秒级。若不可接受，再回头给重建加缓存（本 spec 不预先
  优化）。
