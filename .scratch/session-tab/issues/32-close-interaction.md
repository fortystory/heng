# 32: 关闭的交互：让「要关哪一个会话」在点之前就看得见

Type: implement
Status: ready-for-agent
Blocked by: 21, 31
Part of: ../map.md

**要打通的行为**：关掉会话页上任意一个**非前台**会话是**两步** —— 点它、点 `关闭` —— 而且点
之前屏幕上就写着关的是哪一个。现在这件事要绕：`关闭` 作用在**焦点行**上，而鼠标点一行会连前台
一起切过去，于是点谁谁就成了「脚下这一场」，结果永远是「别关脚下这一场」。

**来源**：维护者 2026-10-12 问「关闭的会话该如何操作？」；随后一轮访谈（Q1–Q19）把三处「票里
已经定了、实现没落地」的偏差与两条新交互一并定死。完整决策见文末 `## 作答`。

## 冻结的验收

- [ ] **单击**会话页一行 = 交键盘 + 落焦点（**不切前台**）；`Enter` = 切到焦点行
- [ ] **鼠标双击**同一行（两次点击同一行、间隔 ≤ 500ms）= 切到那一行；第二次点击不再改焦点
- [ ] **拖选优先**：左键仍是 `down → drag → up`，跨过门槛就不是点击
- [ ] `关闭` 作用于**焦点行**；按钮两档都写 `关闭「<标题>」`，超宽尾省略
- [ ] 关掉一个非前台会话是**两步**（点它 → 点 `关闭`），不需要方向键
- [ ] **只剩一个会话时也能关掉它** → 空宿主态；关掉最后一场**不打 notice**
- [ ] 前台被拒时走**提示行**：`这个会话在前台 · `（MUTED）+ `切到「<下一行标题>」`（ACCENT，
      整段一个命中矩形）；点它 → 前台切到相邻行、**焦点留在要关的那一行**
- [ ] 忙时拒绝照旧（先在那个会话按 `ctrl-c`）；只读预览照旧能关
- [ ] 不二次确认（含关掉最后一场）

## 实现要点

- **双击**：crossterm 0.29 的 `MouseEventKind` 没有双击，SGR 协议也不带 click count —— 只能在
  渲染侧判定，挂在现有那次点击判定上（`release_at` → `click_at`）：同一行 + `GESTURE_WINDOW`
  （500ms，票 28 的退出手势用的同一个常量）。
- **前台例外**：`close_check` 的 `CloseRefusal::Foreground` 改成「只有不是最后一场时才拒」；
  关掉最后一场落到**空宿主**态（票 07 §5 已定义）。
- **提示行**：`CloseRefusal::Foreground` 不再经 notice 进转录，给它一条提示行 + 命中矩形。
  `Attention` 通道现在**没有发送者**（票 28 的欠账），要么接回它，要么新增一个 `CloseBlocked`。
- **按钮点名**：目标取焦点行的标题（票 01 的权威链），截断复用 `fit_title`。
- **顺序**：先做术语迁移（[`.scratch/chinese-ui/issues/09`](../../chinese-ui/issues/09-session-noun.md)），
  再实现本票 —— 本票自己的文案就要用新词（Q18）。

## 作答（2026-10-12，一轮访谈 Q1–Q19）

### 点行与切换（Q1、Q5、Q11）

- 单击 = 交键盘 + 落焦点，**不切前台**；`Enter` = 切到焦点行；**鼠标双击同一行**（≤500ms）=
  切到那一行。这条**推翻票 20 验收第 2 条**（「单击 = 交键盘 + 落焦点 + 能切就立刻切」），
  票 20 已追加评论。
- 拖选优先；双击不引入新的状态机，只在一次点击判定里比 `(行, 时刻)`。
- 过滤输入态下 `Enter` 优先「接受并离开过滤」（票 10 不变），**双击不受过滤态影响** —— 指针
  与键盘焦点正交。

### 关闭（Q2、Q6、Q8、Q12）

- **只剩一场时允许关掉它**（它必然是前台）→ 空宿主态；`Foreground` 拒绝改成「不是最后一场才拒」。
- 被拒的提示进**提示行**；可点段把前台切到目标行的**下一行**（没有下一行就上一行），
  **焦点留在要关的那一行** —— 否则接着点 `关闭` 会关错。
- **不二次确认**（含关掉最后一场）；关到最后一场**不打 notice**（页顶 `0 个`、页区 `没有会话`、
  输入区禁用已经在说同一件事）。

### 屏幕上看得见的东西（Q3、Q4、Q7、Q10）

- `关闭` 两档都**点名**：`关闭「<标题>」`，超宽尾 `…`；**不借页区末行**（那里归 `＋N 场`）。
- 提示行文案：`这个会话在前台 · 切到「<相邻行标题>」`，后半段 ACCENT 且整段可点
  （与票 06 §9 那条提示行同形）。

### 落点（Q9）

- 本票**原地**转 `Type: implement`；本轮已给票 06 / 20 / 07 追加评论；`spec.md` 在实现时加一节。

### 术语：量词「场」淘汰（Q13–Q19）

- 统一说「**会话**」。迁移范围 = **档 2**：`src/`（含代码注释与用户可见文案）、`CONTEXT.md`、
  `docs/`、活跃的 `spec.md` / `map.md`、`tests/` 的断言；**不动**历史票与 ADR（那是记录）。
- 例外：`场外` → `后台`；`一场讨论` → `一次讨论`；`开场` / `清场` 这类固定搭配保留。
- 宿主表读数改 `已装载 N 个 · M 个在跑`；终端标题两段改 `N 个待答` / `N 个跑完`。
- 顺序先迁移后本票；迁移记一条 ADR（历史记录里会一直看得见「场」）。
