# 29: 会话页的标题色分三档（前台 / 已装载 / 只在盘上）

Type: implement
Status: done
Blocked by: 21
Part of: ../map.md

**要打通的行为**：会话页上一眼看出**哪些场已经装载在这个进程里**、哪些只是盘上的一条记录 —— 而
`关闭`恰恰只对前者可用，且切过去要不要装载也由此可知。

**来源**：维护者报告（2026-10-12：「没有办法区分哪些会话启动了，哪些没启动，也就没法判断『关闭』
是否可用」）；[spec.md](../spec.md) §3；决策票 [`04`](04-session-host-and-concurrency.md) §1。

## 验收

- [ ] 标题色三档：**当前前台**（`LIVE` 绿）、**已在宿主表**（`HOSTED` 蓝）、**只在盘上**
      （`MUTED` 灰）
- [ ] 三档**两两不同**（色板里一条测试钉住）—— 撞色就等于没分
- [ ] 「已装载」包含跑着与等人答的那些：颜色只回答**在不在表里**，跑不跑由标记列的 `●` / `?` 说
- [ ] **焦点是字重不是颜色**：焦点与「在不在前台」正交 —— 键盘可以停在任意一行上，拿颜色表达焦点
      会盖掉那一行的身份。焦点另有两条信号（时间列 `ACCENT` + 粗体）
- [ ] 装进来 / 关掉 / 切换都要立刻反映（数据经 `ConsoleRequest::Hosted` 推，**变化了才推**）
- [ ] 缺 cwd 的行仍是整行 `MUTED`（它切不过去）
- [ ] 测试：三档颜色、关掉后退回灰

## 实现记录（2026-10-12）

- **缺口**：`SessionMark` 只有三档（`Idle` 空 / `●` / `?`），而「已在宿主表里、正好空闲」与
  「只在盘上、没装载」**共用同一个空标记** —— 页顶的 `N 场` 说得出总数，说不出是哪几场，于是读的人
  判断不了 `关闭` 对哪一行可用、切过去要不要等装载。
- **颜色分档**：`palette::LIVE`（`LightGreen`）与 `palette::HOSTED`（`LightBlue`），与
  `USER` / `INJECTED` 撞值是刻意的（色板 §3 允许域间撞值）。`MUTED` 那一档早就有。
- **`ConsoleRequest::Hosted { ids }`**：`HostCount` 只给两个数，说不出「是哪几场」，所以另给一条。
  主循环在同一处 80ms 轮询里算出来，**与上一帧不同才推** —— 那是装载与关闭的边沿，不是每 80ms
  一次的事实。`SessionClosed` 那条顺带把它从渲染层的集合里删掉。
- **焦点改成字重**：焦点行原来是 `ACCENT` + `BOLD` 整行着色。现在颜色归「在哪儿」，焦点用
  `BOLD` + 时间列 `ACCENT` —— 两个正交的通道，谁也不盖谁。
- 测试：`tests/session_page.rs` 新增 `the_title_colour_says_where_a_session_is`（三档两两不同 +
  关掉后退回灰）；`src/render/palette.rs` 里一条色板自检。

## 欠账

- **`关闭` 那一档仍然是「全场可用」的观感**：真正能关的只有「已装载、不在前台、没在跑」那几行，
  而页顶那个 `关闭` 入口按的是**焦点行**。焦点停在不可关的那一行时点它，会得到主循环那句拒绝理由
  （票 21 的 `CloseRefusal`）—— 也就是说**能不能关，仍然要靠点了才知道**。真正的做法是让页顶那个
  入口自己在不可关时变灰（或者按焦点行算一个禁用态）。归票 09。
- 三档颜色只在**宽档**下看得全：窄档的会话页按高度丢行，颜色与行一起丢，判据要记在清单里。
