# prototype：左栏「会话」页的形态

Type: prototype
Status: resolved
Blocked by: 02, 04

## 问题

用便宜的帧把「左栏第五签 `会话` 长什么样、怎么点、怎么滚、切换后留住什么」画出来，好在折叠成 spec 之前先看一眼真实的形状。

**范围级决定已在 charting 冻死**（见 `../map.md` 的冻结项 10、11）：这个页签**只走鼠标**（左栏"页签不给键位"的不变量）；新建 = 同 cwd 再加载一场空会话。本票不重开这两条。

## 要画的帧

照 `.scratch/tui-sidebar/prototype/` 的既有套路（纯文本帧 + 一份 README 说明每张帧证明什么），至少覆盖：

1. **签的位置与顺序**：`会话` 放最前（第一条）还是最后；与 `todo`（条件签）同处一行时的顺序；28 列档（四签加新签 = 26 列、剩 2 列填线）与 40 列档各一张。**要证明新签不会被裁掉、也不会把 `todo` 挤掉。**
2. **列表行布局**：标题 + 时间 + 工作区 + 状态标记在同一行怎么排、各占几列；超长标题怎么截；28 列档丢掉哪些字段（照左栏"先丢次要"的既有阶梯）。至少两种行样式对照（平铺 / 带分组头）。
3. **状态标记**：当前前台、后台跑着、后台待答、工作区已不在 —— 各一张帧（或一张帧里四种全有），标出字形与颜色（语义色板）。
4. **滚动与溢出**：条目多于页区时的滚动（左栏既有页没有滚动，这是新东西 —— 要么给焦点行 + `↑`/`↓`，要么截断 + `＋N 场`）；页区只剩几行时的降级。
5. **关闭入口**：`关闭会话` 长在哪（行尾一个字形？页底一行？），点它的命中矩形与确认（`SessionStore::delete` 之外，"关闭"只是从宿主移除、不删盘）。
6. **切走的瞬间**：切到另一条时这一页自己变什么（当前标记移动、后台标记变化）；切回时滚动位置与焦点留住。

## 要定的键位（帧之外的那一半）

- 页内是否给键盘焦点（`文件` / `改动` 页的先例：**点左栏任意处**把键盘交给这一页，`Esc` 只还键盘）；`↑` / `↓` / `Enter`（Enter = 切过去？）/ `Esc` / 关闭键各是什么。
- **不许**动既有键位表（`Tab` 归 `/` 菜单、`Shift+Tab` 归模式、`Ctrl-O` 归整栏），若必须新增要明确说这是新范围。

### §1 页签

`会话` 放**最前**：`会话┆调用量┆todo┆文件┆改动`。

- 尺码（`text_columns` 口径）：会话 4 + `┆` 1 + 调用量 6 + 1 + todo 4 + 1 + 文件 4 + 1 + 改动 4
  = **26 列**。窄档 28 列因此余 2 列 `┄` 填线 —— 新签放得下，`todo` 没被挤掉
  （帧 [`80x24-session-first.txt`](../prototype/frames/80x24-session-first.txt)）。
- 页签**常驻**（票 02 §5）：列表空、store 读不出、`git` 不在 PATH 时它都在。
- 仍**只走鼠标**、不给键位（冻结项 10）；命中矩形沿用 `draw_label_bar` 的既有写法，动作
  = `HitAction::SwitchTab(Tab::Sessions)`（`src/render/tui.rs:8388-8428`）。
- `todo` 仍是有条件的那一签（`src/render/tui.rs:8332-8338`），位置随新签后移一格。

### §2 行布局（含对票 02 的两处回改）

| 档 | 栏宽 | 标记列 | 标题列 | 间隔 | 时间列 | 时间写法 |
|---|---|---|---|---|---|---|
| 窄 | 28 | 1（永远预留） | **21** | 1 | **5** | `刚刚` / `3分` / `2时` / `昨天` / `08-12` |
| 宽 | 40 | 1（永远预留） | **27** | 1 | **11** | `刚刚` / `3 分钟前` / `2 小时前` / `昨天 14:02` / `08-12 14:02` |

- **回改票 02 §1**：宽档时间列从 8 改成 **11**、标题列从 30 改成 **27**。理由：票 02 自己定的
  写法里 `昨天 14:02` 是 10 列、`08-12 14:02` 是 11 列，8 列装不下。
- **回改票 02 §2**：`损坏` 标签排在**时间之前**（标题与时间之间），不是票 02 写的「时间之后」。
  理由：宽档 1 + 27 + 1 + 11 + `损坏`(4) + 1 = 45 > 40，顶出栏宽。它占 4 列 + 1 间隔，从
  标题列扣（画那一行时标题列 22）。
- 行内角色：标记列 1 列 + 标题吃剩余列并尾 `…`（`ellipsize_line` 口径）+ 间隔 1 列 + 时间右对齐定宽。
- 组头占**整行**、成员**不缩进**、组头不给命中动作（票 02 §4 不变）。
- **焦点行 = `ACCENT` + `BOLD` 整行**（与 `文件` / `改动` 两页同档，`src/render/tui.rs:8149-8155`）；
  当前前台的 `▍` 只占标记列、不加 `BOLD`（票 02 §2 不变）。

### §3 状态标记

一张字不改：`▍`/`ACCENT`（前台）、`?`/`WARN`（待答）、`●`/`PLAIN`（活跃）、空闲留空、
cwd 不存在整行 `MUTED`、流损坏尾 `损坏`/`BAD`（位置按 §2 的回改）。四种标记同屏的样子见
帧 [`120x24-session-first.txt`](../prototype/frames/120x24-session-first.txt)（前台 + 活跃 +
待答 + 损坏）与 [`120x24-attached.txt`](../prototype/frames/120x24-attached.txt)（cwd 不存在
那一组整组 `MUTED`）。

### §4 关闭入口

**页顶一行**：左端读数（§5），**右端 `新建` + `关闭`**（都 `ACCENT`、都可点）。`新建` 是票 07
定的入口（新建 = 同 cwd 再加载一场空会话、旧的留着），它与 `关闭` 挤在同一行右端。

- 命中矩形各盖自己那几列；`关闭` 点它 = 关闭**焦点行那一场**（语义归票 07：前台不许关自己、
  有回合在跑就拒绝、不确认）；`新建` 点它 = 新建并切过去。本票只给入口形状。
- **不选**行尾 `✕`：它挤压标题 2 列，且与截断后的 `…` 落在同一段里读起来像正文；误点一行
  = 卸载一场会话，而命中层没有确认（`src/render/tui.rs:1600`）。
- **不给键位**：鼠标入口之外没有单键（新建另有既有的 `/clear`）。
- 页区 < 6 行时这一行整个让位（§6 的第三档）——那时两个入口都只剩 `/clear`。

### §5 并发读数（票 04 §5 的落点）

**会话页页顶那一行**，与两个入口同行：左端 `16 场 · 1 场在跑`（`MUTED`），右端 `新建` + `关闭`。

- 前半 = 宿主表里的会话数，后半 = 状态为 `RunningTurn` 的场数（票 04 §3 的 `watch` 快照派生）。
- **宿主表为空时这一行是 `0 场`、右端只剩 `新建`**，页区写 `没有会话`，输入区禁用（票 07 §5
  的**空宿主**态）。
- 新文案，要在 `src/render/wording.rs` 新增；**回改票 02 §5**：整页文案从「只有两句」放宽为
  「空态四句（`还没有历史会话` / `读不出会话列表` / `没有会话` / `没有命中的会话`）+ 这一条读数」
  —— 前两句是「store 里没有」、第三句是「宿主表里没有」、第四句是「过滤没筛到」，三回事。
- **过滤态下这一行整行让给过滤行**（左端 `会话` + 查询串、右端 `n 个命中`）：读数与 `新建` /
  `关闭` 都让位，退出时整行还原（[票 10](10-session-list-search.md) §1）。
- 帧 [`120x24-top-readout.txt`](../prototype/frames/120x24-top-readout.txt)、
  [`80x11-small-page-final.txt`](../prototype/frames/80x11-small-page-final.txt)（两张帧里
  右端只有 `关闭`，`新建` 是票 07 之后补上的；形状不变，右端多一个 4 列词）。

### §6 溢出与降级（三级阶梯）

不滚动（票 02 §7 维持）：末行 `＋N 场`（`MUTED`，全角 `＋`），`N` = **一条都没露过面**的会话数。
预算要把已画出的组头与读数行扣掉。前台会话永远可见（它那组钉顶、组内第一行）。

| 页区行数 | 组头 | 页顶读数行（含 `新建` / `关闭`） |
|---|---|---|
| ≥ 8 | 画 | 画 |
| 6–7 | **不画**（降级成平铺） | 画 |
| < 6 | **不画** | **不画** |

- 依据：`80x10` 页区 5 行时，带组头只有 3 场可见，平铺 4 场
  （帧 [`80x10-small-page.txt`](../prototype/frames/80x10-small-page.txt) 与
  [`80x10-small-page-no-headers.txt`](../prototype/frames/80x10-small-page-no-headers.txt)）；
  `80x11` 页区 6 行时读数行仍在（帧
  [`80x11-small-page-final.txt`](../prototype/frames/80x11-small-page-final.txt)）。
- **这回答了票 02 §9 点名的那条**：窄档组头在小组区里太贵 —— 票 06 已按此回改票 02 §4 的
  「窄档照画组头」。

### §7 页内键盘与命中

点左栏任意处（页签条或页区）→ 键盘交给会话页（照 `take_sidebar_keyboard`，
`src/render/tui.rs:5575-5619`）。**这是继 `文件` / `改动` 之后的第三页**——`docs/render.md:543-550`
那份名单要加一页。

| 键 | 动作 |
|---|---|
| `↑` / `↓` | 在**会话行**之间移焦点（组头不可聚焦、跳过；越界停住，不绕回） |
| `Enter` | 切到焦点那一场（票 01 §6） |
| `r` | 改名（票 01 §6，复用常驻 `editor`） |
| `/` | 进**列表过滤**（[票 10](10-session-list-search.md)）：页顶那一行整行变过滤行、实时筛；过滤态下 `Enter` = 接受并离开过滤、`Esc` = 取消或清过滤，可打印字符都进查询串（`r` 与 `Enter` 的切会话动作在过滤态下先让位） |
| `Esc` | 只把键盘还给输入区（一次手势一层，不取消回合）；过滤态下先花掉一层（见上一行） |

- **不新增任何 `Ctrl-*`**；`Tab`（`/` 菜单）、`Shift+Tab`（模式）、`Ctrl-O`（整栏）不动。
- 点击行为照票 02 §6：单击任一行 = 交键盘 + 落焦点 + 能切就立刻切；点前台那一行只做前两步；
  cwd 不存在 / 流损坏两行不切、焦点照落、各回一句提示行。

### §8 重画与保位（清掉 map 的「尚未明确」里那条雾）

后台标记会随状态变（票 04 §3/§4），所以这一页会重画。重画**不抢焦点行**：

- 焦点按**会话 id** 保存，重扫后按 id 找回 —— 行序会随 mtime 漂移（票 02 §10），按行下标保位
  会指到另一场会话上。
- 焦点那一场从列表消失时（store 变了）回落到**当前前台那一场**，不落到第 0 行。
- **没有阅读位置要保**：不滚动，页面永远从列表顶画。
- 页签选择是进程级（票 04 §8），切走再切回仍在会话页；焦点行也跟着留住。

### §9 退出被拒时那个可点入口（票 04 §7 交给本票画）

提示行（主列底部，与输入区同列同宽）：

```
还有 2 场在跑 · 切过去取消「会话宿主表与前台指针」
└───── MUTED ─────┘└──────── ACCENT（可点）────────┘
```

- 前半 `还有 N 场在跑 · ` 用 `MUTED`；`切过去取消「<标题>」` 整段用 `ACCENT`，整段是一个命中矩形。
- 点它 = 切到在跑集合里的第一场（票 04 §7 的语义）；标题是那一场的标题（票 01 的权威链）。
- 帧 [`120x24-exit-refused.txt`](../prototype/frames/120x24-exit-refused.txt)；提示行的宽度与
  出口位纪律仍归既有提示行那一套（`docs/render.md:532-541`）。

### 2026-10-12：[票 32](32-close-interaction.md) 把关闭那一路定死

- 键位表里 `Enter` = 切到焦点那一行**要落地**（现在 `Key::Enter => {}` 是空键）；**鼠标双击**
  同一行也切前台（同一行 + ≤500ms）。
- `关闭` 两档都**点名**：`关闭「<标题>」`（超宽尾 `…`）；仍只走鼠标。页区末行不借 —— 那里归
  `＋N 场`。
- 关闭被拒的提示进**提示行**（不再是转录里的一句 notice），可点段把前台切到相邻行、**焦点留在
  要关的那一行**。
