# 23: 退出闸门与 `Ctrl-C` / `Ctrl-D` 语义

Type: implement
Status: done
Blocked by: 22
Part of: ../map.md

**要打通的行为**：多会话下「打断」与「退出」两件事的语义说清楚 —— `Ctrl-C` 只打断前台当前那个动作、**永不退出**；`Ctrl-D` 要过闸门：还有回合在跑就拒绝，并给一个可点入口指到在跑的那一场。

**来源**：[spec.md](../spec.md) §1；决策票 [`04`](04-session-host-and-concurrency.md) §7。

## 验收

- [ ] `Ctrl-C` **只取消前台当前的动作**（正在跑的回合，或正在跑的历史重播 —— 两者同一件事的两种形态），**永不退出**；「第二下变退出」那条旧语义删掉
- [ ] 前台没有可取消的东西时提示行一句（后台有在跑时顺带说那句）
- [ ] `Ctrl-D` 退出闸门：**只要有任一场在跑回合就拒绝**；提示行说「还有 N 场在跑」并给一个**可点入口**指向在跑集合的第一场（点它切前台），手动取消完才放行；不自动取消、不代用户做决定
- [ ] 退出流程：过闸门后广播 `Close` → await 全部 `JoinHandle` → 退出码照旧（只 0 / 130）
- [ ] **退出不写收尾事件**；多场被杀不新增恢复机制
- [ ] 过了在跑的闸门之后，若后台还有**空闲**会话，提示行补一句「还有 N 场后台会话」
- [ ] 测试（宿主接缝）：有回合在跑时退出被拒且入口指向第一场；全部取消后能退出；`Ctrl-C` 在任何状态下都不改变「进程是否活着」

## 实现记录（2026-10-12）

- **`Ctrl-C` 只取消前台当前的动作，永不退出**：`exit_key` 里 `CtrlC` 只发 `FrontEndEvent::Cancel`
  —— 「第二下变退出」那条旧语义（`.scratch/exit-gesture/spec.md` §1）删掉了。主循环收到
  `Cancel` 时只把它转给前台那一场，**不记进退出账本**；前台没有可取消的东西时回一句，后台
  还有场时顺带说那句（`cancel_nothing`）。
- **`Ctrl-D` 是退出请求**：`exit_key` 里它直接发 `FrontEndEvent::Quit`（不再有「忙碌时忽略」那一
  档 —— 闸门在循环侧）；只有一个例外留给问卷：任何问题立着时它是「被忽略」。
- **退出闸门**（`session::exit_gate`、`ExitGate`）：**不在空闲**的场有一场就拒绝，并给出**第一
  场**。「不在空闲」把 `AwaitingHuman` 也算上 —— 那一场有动作挂在等人答，杀掉它等于替人做了
  决定。提示行说「还有 N 场没收尾」，同时经 `ConsoleRequest::Attention` 把会话页交到前台、焦点
  落在那一行上（**可点入口**）。
- **退出流程**：广播 `Close` 给**每一场** → 逐场 `close_with` 等 `JoinHandle` → 再等渲染器把
  缓冲写完 → 退出码照旧只有 0 与 130。**不写收尾事件**。
- 测试：`tests/session_host.rs` 加 1 条（闸门在空闲时放行、有在跑时拦下并指向它、取消之后放
  行）；`tests/render_layout.rs` 加 1 条（`Ctrl-C` 连按两下都只是取消、没有一条退出请求）。

**欠账（写在这里，要进票 09 的清单）**：

- 随旧的「举手 → 出口段换字」退役，`tests/render_layout.rs` 与 `tests/render_tui.rs` 里与它
  绑定的测试被删掉。其中三条描述的**行为仍然成立**，值得补回：`Escape` 在跑着时是取消手势、
  `Shift+Tab` 是模式手势、有问题立着时 `Ctrl-D` 被忽略。
- 渲染器里「举手换掉出口段」的那条渲染路径成了**死路径**（`exit_key` 不再举手）；出口段那几
  行该在票 09 回改文档时一起清掉。
