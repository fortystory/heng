**要打通的行为**：左栏多出第五签 `会话`，它把盘上跑过的会话列出来 —— 每一行看得懂（名字、多久没动、属于哪棵检出），并且能用鼠标与页内键盘操作。这一片**先不切会话**（下一片接），但列表本身要完整可用。

**来源**：[spec.md](../spec.md) §3、§4；决策票 [`02-list-rows-and-grouping.md`](02-list-rows-and-grouping.md)、[`06-session-page-shape.md`](06-session-page-shape.md)。

## 验收

- [ ] `会话` 放页签条**最前**（`会话┆调用量┆todo┆文件┆改动`）；窄档 28 列五签占 26 列、余 2 列 `┄`；页签**常驻**；页签仍只走鼠标
- [ ] 行 = 标记列 1 + 标题 + 间隔 1 + 时间；窄档 `21 / 5`、宽档 `27 / 11`；标题按显示列宽截断并尾 `…`（不按字节）
- [ ] 组头按检出：家族探测成功写 `--show-toplevel` 目录名；失败按 cwd 字符串各成一组；重名写尾两段路径；组头占整行、不带计数、**不可点**、空组不画
- [ ] 排序：前台所在组钉组顶 → 组间 / 组内 mtime 降序 → id 降序兜底 → 读不出 mtime 的排最后
- [ ] 状态标记：当前前台 `▍`+`ACCENT`（不加 `BOLD`）、待答 `?`+`WARN`、活跃 `●`+`PLAIN`、空闲留空、cwd 不存在整行与组头 `MUTED`、流损坏尾 `损坏`+`BAD` 排在时间**之前**
- [ ] 不滚动；末行 `＋N 场`（`N` = 一条都没露过面的会话数）；前台永远可见
- [ ] 三级降级阶梯：页区 ≥8 行 = 组头 + 页顶读数行；6–7 行 = 丢组头保读数行；<6 行 = 两者都不画
- [ ] 页顶一行：`N 场 · M 场在跑` + 右端入口（本片先画 `新建` / `关闭` 的位置与命中，动作由后续片接）
- [ ] 空态两句：`还没有历史会话` / `读不出会话列表`；**无 `git` 不产生文案**；单个 cwd 失效只体现在行级与组头级 `MUTED`
- [ ] 页内键盘：点左栏任意处交键盘、`↑`/`↓` 移焦点（跳过组头）、`r` 改名（复用常驻编辑器）、`Esc` 还键盘；点击任一行 = 交键盘 + 落焦点（能切就切留到下一片）
- [ ] 只读轻路径：整轮约 10 ms；**不走 `summarize`**、**不走 `EventLog::open`**、无索引无落盘缓存
- [ ] 测试：帧级断言照 `tests/render_layout.rs` 的写法（宽窄两档、组头、`＋N 场`、四级标记、降级阶梯、空态），键位断言照既有左栏两页的写法
