# 24: 列表过滤

Type: implement
Status: done
Blocked by: 17
Part of: ../map.md

**要打通的行为**：281 场里够得着我要的那一场 —— 在会话页上按 `/` 打字，列表实时只剩命中的；命中多少写在过滤行上；不想要了 `Esc` 一层层退回去。

**来源**：[spec.md](../spec.md) §3；决策票 [`10-session-list-search.md`](10-session-list-search.md)。

## 验收

- [ ] 页内键盘 `/` 进过滤（**页签仍只走鼠标**，不新增鼠标词）；页顶那一行**整行**变成过滤行：左端 `会话` + 查询串，右端 `n 个命中`
- [ ] 判据 = **标题 + 组头目录名**、空格分词、**大小写不敏感**、各词 **AND**；**只在前缀轻路径已派生的那份列表上筛**（不额外读盘、不搜消息正文）
- [ ] 实时生效（改一个字符就重筛），没有「按了回车才生效」那一档
- [ ] 结果：只剩命中的会话行、**组头保留且不因过滤改写**、空组不画；**过滤态下钉顶让位**（前台不在结果里就不显示、不另给提示）
- [ ] 过滤行右端复用既有的「n 个命中」措辞（0 也同一句）；**标题不高亮**（`HIT` 底色仍只属时间轴）
- [ ] 末行仍 `＋N 场`（截断照旧）；空结果两句：过滤行 `0 个命中` + 页区 `没有命中的会话`
- [ ] `↑`/`↓` 在命中行之间移焦点；`Enter` = 接受查询并**离开**过滤态；`Esc` 输入态 = 取消这次过滤（还原草稿）、已生效态 = 清过滤；两处键盘都留在页里，再一下才还输入区
- [ ] 草稿复用常驻编辑器（进过滤时整份收起、退出时原样还回）
- [ ] 过滤态是**进程级**（切走再回来仍在），退出后钉顶 / 组序 / `＋N` / 页顶行全部还原
- [ ] 测试（帧 + 键位接缝）：过滤后的帧、组头保留与空组不画、`0 个命中` 与空结果文案、`Enter` / `Esc` 两层

## 实现记录

- **入口是页内 `/`**（页签条仍只走鼠标）：`SessionsFilter`（`SessionsPage` 的本体字段，**进程级**
  —— 与会话无关，所以不进票 08 那张 `SessionId → 轻状态` 表）。进过滤时把**整份**草稿
  `std::mem::take` 进 `draft`，接受或取消时原样还回 —— 一个绘制件都不新造。
- **判据**：标题 + 组头目录名、空格分词、大小写不敏感、各词 AND；只在前缀轻路径已派生好的
  那份列表上筛（不额外读盘、不搜 id、不搜消息正文）。
- **页顶那一行整行变过滤行**：左端 `会话` + 查询串、右端 `wording::hit_count`（0 也是同一句）；
  读数与 `新建` / `关闭` 让位，**不额外吃页区行** —— 三级降级阶梯一字不动。标题不高亮。
- **实时生效**：改一个字符就 `retoken` + `refilter`，没有「按了回车才生效」那一档。
- **结果形态**：`SessionsPage::shown` 是「现在要画的行」，组头保留、空组不画；过滤态下
  **钉顶让位**（排序回到 `listing::sort_by_time` 的 mtime 降序 + id 兜底）。末行的 `＋N 场`
  在过滤态下数的是「命中里没放下的」（决策票 10 §3）；过滤行右端的命中读数才是「筛出多少」。
- **键盘**：输入态下可打印字符 / `Backspace` 进查询串、`↑`/`↓` 移焦点、`Enter` 接受并离开输入
  态、`Esc` 取消这次过滤；已生效但没在输入时 `Esc` 清过滤、再一下才还键盘。`r` 在过滤态下
  不收（`sessions_key` 的匹配顺序保证）。
- 顺带补上票 17 漏掉的一处：**点页签**也要把键盘交给会话页（`sidebar_keyboard` 的名单原来只有
  `文件` / `改动`，而会话页从票 17 起就有页内键位），并落第一行焦点。
- 新增 7 条用例（`tests/session_page.rs`）：实时筛与过滤行形态、判据的大小写与 AND、空结果两句、
  组头保留与空组不画、`Enter` / `Esc` 两层、钉顶让位、`＋N 场` 的基数。
