# 03: 流程页的信息层

Type: implement
Status: done
Blocked by: 02

> 规格：[`../spec.md`](../spec.md) §2–§3。帧：[`../prototype/frames.txt`](../prototype/frames.txt)
> 的「A 等权全图」（42 / 60 档、三态）。

**要建的：** 轨道从「五个节点 + 当前高亮」长成一张读得动的图：已过节点带停留时长、流式带
字数、工具带工具名与已跑时长、当前节点展开子块、工具之后画循环回边、底部固定说明区与回合
统计、空闲时定格上一回合的完整路径。宽档再放宽统计。

## 具体行为

1. **侧注**（右对齐）：
   - 已过节点的停留时长；
   - 等模型段的定格值优先用 `MessageCompleted.first_token_ms`；流式段的定格值 =
     `MessageCompleted.at - TurnStarted.at - first_token_ms`（`None` 时整段算等待）；
   - 流式节点带「已收字数」（实时取 live 文本长度，定格取 `MessageCompleted.text` 长度）；
   - 工具节点带工具名与已跑时长；工具自身运行时长用 `ToolCallCompleted.duration_ms`。
2. **当前节点子块**（至多 2 行，MUTED，`├` / `└` 缩进）：
   - 等模型：`拼请求 · 投影 → 身份 → 裁剪` 与 `预算预检 · 请求已发出`（**静态清单**，不假装
     知道子步骤，见 spec 用户故事 19）；
   - 工具：`权限门 · 已允许 / 已拒绝 / 询问中`（来自 `PermissionAsked` / `PermissionDecided`）
     与 `bash · 执行中 N s`；`SessionState::AwaitingHuman` 时写「等你批准」。
3. **回边**：工具调用之后始终画 `↺ 还有工具调用 → 回到「等模型响应」`。它是结构，不随
   「还有没有工具调用」出现或消失。
4. **说明区**：贴底、高度固定，小节线 `─` + 当前节点 1-2 句解释 + 统计一行
   （`2 次迭代 · 1 次工具 · 36%`）。说明文案长短不许挤动轨道的行位置。
5. **空闲态**：轨道显示上一回合五个节点全部 `✓` + 各自停留时长；头部「空闲」；说明区
   「上一回合已收起。等你发一句话。」+ 上一回合统计。
6. **异常收尾**：`Aborted` → 收尾 `✗` + WARN；`Error` / `BudgetExhausted` / `MaxIterations` /
   `MistakeLimit` → `✗` + BAD；说明区写对应的那句。`Completed` → `✓`。
7. **60 档**：统计一行放宽到输入/输出 token；说明一句一行；工具子块可多一行「结果待追加」。
8. 文案全部进措辞层；颜色只从语义色板取，不新增颜色。字形语法照旧：框架档虚线、内容档实线。
9. 脉冲只读现有的 60ms 帧计数器：耗时与「⟳」每帧刷新，**不新增定时器**。

## 验收

- [ ] 42 档三态帧（等模型 / 工具 / 空闲）各至少一条帧断言，覆盖侧注、子块、回边、说明、统计。
- [ ] 60 档一帧：统计放宽成输入/输出 token，且行宽不超。
- [ ] 权限拒绝帧：子块显示 `已拒绝`，回合照常收尾（不卡在工具节点）。
- [ ] `Aborted` 帧：收尾 `✗` 且说明与颜色档正确（断言帧文字，颜色在真机清单里看）。
- [ ] 多工具调用：工具侧注跟随最近一次调用刷新；回边行不重复、不消失。
- [ ] 说明区高度固定：两条不同长度的说明帧里，轨道首行所在行号相同。
- [ ] 措辞断言：说明文案、统计格式、节点名都从措辞层取。
- [ ] `cargo test` 全绿、`clippy` 与基线同、`fmt --check` 只留既有的两处漂移。
