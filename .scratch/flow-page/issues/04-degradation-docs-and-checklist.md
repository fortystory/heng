## 具体行为

1. **高度阶梯**（`r` = 右栏高 − 页签条 3 行）：
   - `r ≥ 18`：完整（头部 + 空行 + 13 行轨道 + 说明区）；
   - `14 ≤ r < 18`：丢统计行，说明压到 2 行；
   - `10 ≤ r < 14`：轨道退成窗口，只留当前节点与前后各一个，被裁那一端画 `⋮`；说明 1 行；
   - `r < 10`：只画当前节点一行 + 说明一行，不画小节线。
2. **文档**：
   - 新增 ADR 0025：右栏不止一页（并记录流程页的数据来源选择 —— 只读 TUI 侧事件推导、
     不新增事件、不动 agent）；
   - 回改 ADR 0024 里「右栏里只有一页 —— 轨迹」那半句；
   - `docs/render.md` 补右栏两页与流程页；
   - `CONTEXT.md` 新立词条**流程页（FlowPage）**；
   - `docs/tui-manual-checklist.md` 加真机项：42 列中文节点名的字形对齐、页签点击、当前节点
     的颜色对比、矮终端（24 / 16 行）降级、宽档 60 列的统计行。
3. **回归确认**：plain 与 headless 渲染器输出不变、事件 schema 不变、键位表不变、轨迹页除
   下移 3 行外语义不变、模型可见文本零改动。
