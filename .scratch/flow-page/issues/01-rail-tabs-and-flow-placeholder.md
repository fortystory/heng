# 01: 右栏页签条与「流程」占位页

Type: implement
Status: done
Blocked by: —

> 规格：[`../spec.md`](../spec.md) §1。形状定案：[`../prototype/README.md`](../prototype/README.md)。

**要建的：** 右栏从一页变成两页。顶部出现 `轨迹┆流程` 页签条（3 行），点「流程」切过去看到一行
占位说明，点「轨迹」切回来；轨迹页除整体下移 3 行之外一个字不变。这是后面三票的落脚点 ——
先有地方放，再往里填东西。

## 具体行为

1. 新增 `RailTab { Trace, Flow }`，默认 `Trace`。它住 `TuiState`，与左栏 `tab` 同一档：纯视图
   偏好，只活一次进程，不落盘、不跨会话、切会话不重置。**不进** `View`。
2. 右栏顶部 3 行页签条：上下两条 `┄`，中间一行标签。画法复用左栏 `draw_label_bar`：未选中
   MUTED、选中 ACCENT + BOLD、标签之间 `┆`、余下用 `┄` 填满。标签文字进措辞层。
3. 排版新增两个矩形：页签标签行与右栏内容区（页签条之下到底边）。轨迹的两个矩形改在内容区
   内计算 —— 整体下移 3 行，横带档位、账本宽度、滚动语义都不动。
4. 点击页签切页：新的命中动作 + 命中矩形；矩形只记**这一帧真画出来的标签**。鼠标分派在现有
   顺序里加一段（与左栏页签同层；两者互不重叠，顺序只为确定性）。右栏没画出来时，矩形与
   命中一并失效。
5. 流程页此刻只画一行占位（措辞层那句话，与左栏「此页尚未实现」同一族的语法）。
6. 键位表零增删：`Ctrl-V` 仍然只管开/关右栏；右栏拿住键盘时的键位表不动。

## 验收

- [ ] 120×24 帧：右栏可见时顶部有 `轨迹┆流程` 两签，默认「轨迹」选中；轨迹内容整体下移 3 行。
- [ ] 点「流程」→ 帧里出现占位行；点「轨迹」→ 切回，横带与账本与改动前一致（除下移）。
- [ ] `Ctrl-V` 关掉右栏后再开：帧里没有页签条残留，命中矩形为 `None`。
- [ ] 宽度不够使右栏放不下时：不画页签条、不 panic、主列照旧拿回全部宽度。
- [ ] `layout` 断言：页签标签行与内容区的几何、内容区高度 = 右栏高 − 3。
- [ ] 至少 3 条新帧断言；`cargo test` 全绿、`cargo clippy` 与基线同、`cargo fmt --check` 只留
      既有的两处漂移。
