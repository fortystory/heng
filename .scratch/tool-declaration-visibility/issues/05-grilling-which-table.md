# 看得见的是哪张表、哪个时刻的那张

Type: grilling
Status: claimed
Part of: ../map.md
Blocked by: 04

## 问题

[工具声明在界面上以什么形态可见](04-grilling-visible-shape.md) 拍定了**形态**。本票拍**内容**：

界面上摆出来的那份工具声明，**是哪一张表**、**哪个时刻的那张**。

### 哪一张表

1. **主会话那张** —— `src/cli/interactive.rs:223-229` 建的那张。
2. **执行者那张** —— `Registry::for_executor()`（`src/tools/registry.rs:70-78`）的**子集**
   （滤掉不可委派的那些）。界面上要显示的是子集还是全集？（[票 01](../research/01-tool-table-shape.md)
   第 1 节说主会话那张覆盖得了会话里出现的每一次调用。）
3. **讨论 CLI 那张** —— `src/cli/discuss.rs:180-187` 与主会话那张**逐字同形**，讨论者与合成器共享它
   （`docs/discussion.md:17`）。所以这一档大概**不用**单独决定 —— 但要写清楚是「同一张，
   所以不用管」还是「要分别说」。
4. **MCP server 侧那批工具** —— **永远不进表**（`src/events.rs:230-233`）。
   界面上有没有一句要说清「这张表里没有 server 自己的工具」？
   （今天 Schema 面已经有一句同类的降级话：`src/render/wording.rs:549`。）
5. **动态工具那批** —— 来自 `config.toml` 的 `[tools.<namespace>.<tool>]`
   （`src/config.rs:1591`、`:1694`），条数与内容**不受代码控制**。界面上怎么对待它们
   （与内建的一视同仁？还是分开说？）。

### 哪个时刻的那张

1. **今天那张 vs 当时那张**：老会话重开时，工具表是**今天**建的那张
   （`src/cli/loading.rs:121-139` 会重新建一张）—— 不是当时那张。界面上**说不说这句话**？
   在哪儿说：来源名（照系统提示词那条的做法，`src/render/wording.rs:1566`）、面里的一行、
   还是只进文档？
2. **组装期那张 vs 会话中途那张**：表在会话中途**不变**（[票 01](../research/01-tool-table-shape.md)
   第 1 节），所以这一对今天是恒等的 —— 但这一条**是这次改动的前提**，它变了就得重答。
   本票要明确写下这个前提，好让将来有人动它时知道回来重看。
3. **哪一次请求用的那张**：provider 请求里的 `tools` 数组就是这张表（`src/provider/openai.rs:441-455`），
   所以「这张表」与「这个会话用的工具」是同一件事 —— 除非将来工具表按 agent 分开。

## 怎么走

**HITL** 票。开工前调用两次 Skill 工具，分别指定 `grilling` 与 `domain-modeling`。
