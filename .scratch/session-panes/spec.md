## 问题陈述

1. **一屏只有一个会话。** 宿主表里可以有几个，但前台指针全进程唯一，轨迹与输入区都绑在那一个上；
   同时盯两个会话（一个在跑、一个在等人答）只能开两个终端。
2. **轨迹占着主列。** 轨迹是主列页签条的第二页，看轨迹就看不到对话；它在 28 档里的价值远低于
   对话，却和对话抢同一块宽度。
3. **每会话的视图状态是单例。** `View` 整块、`cwd`/`home`、文件索引、命令名册、`pending` 都在
   全进程一份，切会话靠「整块换投影 + 重放」；切到别 cwd 的会话后标题与 `@` 候选还钉在启动目录。
4. **宽度预算已经越界。** 120 列两侧栏全开时主列只剩 38 列，低于 `MIN_WIDTH = 40`；今天没有任何
   让位规则。
5. **在 herdr 里更窄。** herdr 客户端从终端宽度里扣掉自己的侧栏：外层 120 列的终端里 heng 只见
   94 列，落左栏 28 档；用户默认想收掉左栏，但今天只能每次手动按 `Ctrl-O`。
6. **平铺没有入口，也没有「哪些会话在屏上」这个概念。** 宿主表是「活着的会话」全表，屏上只显示
   前台一个。

## 解决方案

把外壳从「一次一个会话 + 左栏 + 主列页签条」改成**顶部页签条 + 最多四个会话平铺 + 右栏**，
左栏保留并改为只回答「状态」。

- **顶部页签条**（2 行、横跨整屏）：列**宿主表**（活着的会话），只写标题 + 焦点 + 集合成员标记；
  右端放平铺按钮与右栏开关；多了收成 `+N`。
- **平铺**：一个显式的有序集合（`Vec<SessionId>`，≤ `[ui] tile_limit`，默认 4，不重复）；
  排法 1 独占 / 2 左右 / 3 L 形 / 4 上下各二；几何不够自动回标签态。焦点格 = 宿主表前台。
- **右栏**：全局一份、跟焦点会话，顶部页面标签只在多页时画；轨迹是它的第一页。宽度同左栏制
  （40 / 28 / 隐藏），窄屏先让位；`Ctrl-V` 一次按下开栏并把键盘交给它。
- **左栏**：保留全部四页，但顶部页签条接管「显示哪几个」，左栏会话页只回答状态、时间、分组与
  过滤；平铺态自动收起；herdr 里默认关。
- **底部三行**（状态行 / 输入区 / 提示行）全局一份、读焦点格；状态行加一段全局读数
  「另有 N 个在跑 / M 个等人类」；输入区草稿与历史每会话各存。
- **视图状态**：`View` 从单例改成每会话一份（`HashMap<SessionId, View>`）；`cwd` / `home` /
  文件索引 / 命令名册 / `read_only` / `pending` 一律每会话；浮层本体仍全局一份。
- **配置**：`[ui] tile_limit` 与 `[ui] sidebar` 两个新键；herdr 只判 `HERDR_ENV == "1"`，且只当
  左栏启动初值。

## 实现决定

### A. 外壳与几何

1. **顶部页签条**：横跨整屏、占 2 行（标签行 + 它下面一条虚线）。**屏高 < 20 时收成 1 行、
   不画虚线**。
2. **左栏顶部下移 2 行**：`SIDEBAR_TOP_GAP` + 身份行 + 3 行左栏页签条整体从顶部条之下开始。
3. **右栏从顶部条之下起算**，与主列同高；右栏自己的页面标签在右栏内部横排，**只有一页时不画**。
4. **外壳开销仍是 9 行**：顶部 2 + 状态行 1 + 两条线 2 + 输入区 3 + 提示行 1。底部三行（状态行 /
   输入区 / 提示行）**只跨 pane 区，不跨右栏**；右栏从顶部条一直到底。
5. **右栏让位算法**（标签态）：右栏档从 40 往下降（40 → 28 → 隐藏），取第一个能让主列 ≥
   `MIN_WIDTH`(40) 的档；**左栏档不动**。结果：120 列两侧栏同开 → 右栏 28、主列 50；
   ≥ 122 列右栏才是 40；< 98 列右栏隐藏（左栏在 28 档时）。
6. **pane 几何**：标签态一个格的宽度下限 40；**平铺态 32**（票 08 的让步）。
   排法照冻结项：1 独占 / 2 左右 / 3 L 形 / 4 上下各二；任一格低于下限 → **自动回标签态**。
   高度也判：3 / 4 格需要屏高 ≥ 30（24 行只撑得住 2 格）。
7. **平铺态左栏自动收起**（`Ctrl-O` 给一句回执）；**右栏照开**。pane 区宽按「≥ 32 × 列数 + 间隔」
   算：94 列扣右栏 29 → 主列 65 → 2 格各 32 成立。

### B. 宿主表、平铺集合与焦点

8. 平铺集合是 **`Vec<SessionId>`**：有序、按加入顺序（不随活跃度漂）、**不允许重复**、上限
   `[ui] tile_limit`。`SessionId` 是唯一合法的成员键（**不用宿主表下标**——下标会随关闭左移）。
9. **焦点格 = 宿主表前台**（`watch<SessionId>`）。平铺态内换焦点只改这个指针，几何不变。
10. 边界三条：集合为空时按 `Ctrl-R` 进平铺 → **自动把焦点加入**；集合非空而焦点不在集合里 →
    **拒绝进平铺**并提示；**只剩一个 → 自动回标签态**。
11. 生灭：关闭 → 从集合移出、焦点给集合里的下一个；新开 / 装载 → **自动加入**；
    `/clear` 翻页 → 新会话**接替**旧位。满员再加 → **拒绝**，提示行一句
    `平铺最多 {N} 个；先移出一个再加`。
12. `[+ 加入]` 格**参与布局**：集合 n 个时按 n + 1 格排；满员时它不画。点它打开会话选择器
    （复用既有 picker 通道）。

### C. 键盘与鼠标

13. **两态**：`Ctrl-R`（忙闲都生效）+ 顶部条的平铺按钮。
14. **平铺态**：`Ctrl-1`…`Ctrl-4` 直接跳第 N 格；鼠标点格子；焦点格标题行 `×` 移出。
15. **标签态**：点标签切前台；`Ctrl-左右方向键` 切标签。
16. **左栏点击语义不改**：单击落焦点行、`Enter` 或同一行双击切前台；加入集合只走 `[+ 加入]`。
17. **`Ctrl-V` 改指右栏开关**：一次按下 = 开栏 + 把键盘交给右栏；再按 = 交还键盘 + 关栏；
    点输入区 = 交还键盘但右栏留着；屏宽 < 80（右栏隐藏）时给一句回执。
18. **`map_key` 今天忽略所有修饰键**（只有 `Shift+Enter` 一个特例）：`Ctrl-1…4` 与 `Ctrl-方向`
    要求先加修饰判断；`Ctrl-方向` 在部分终端 / 复用器里可能被吃掉，**鼠标点击始终是退路**。

### D. 右栏与轨迹

19. 右栏是**全局一份、跟焦点会话**的页面容器；页面标签横排、单页不画；后续页面（团队、任务板）
    只保证容器留得下。
20. **右栏里轨迹的三种宽度形态**：40 档保九列时刻、弃行尾用量（正文 31 列）；28 档是**缩略索引**
    （不画时刻、不带用量，正文 28 列）；**组头保留、放弃「并进虚线」**，组头独占一行、短写。
21. **时间轴只画 Compact 一档**（2 行、一行三态）。
22. **轨迹的宽度来源唯一 = 右栏内宽**；`trace_width` 不再跟主列宽度，`trace_tier_width` 也按右栏宽
    并纳入重放判据。**两态切换不重放轨迹**（右栏宽度由屏幕宽度档决定，与两态无关）；只有屏幕宽度
    跨档才重放。
23. 右栏里点开的详情覆盖层关掉时**还原给右栏自己的滚动位置**；覆盖层本身整屏居中，不缩进右栏。

### E. 视图状态归属

24. **`View` 从单例改成 `HashMap<SessionId, View>`**：`painted`、`block_at`、`trace_groups`、
    `turn_rail`、两个宽度、`colors`、`turn_totals` 全部每会话一份；切会话不再「整块重造 + 重放」。
25. **没有新的「每 pane」状态**：因为集合不允许同一会话占两格，`Viewport`（滚动意图）留在
    `SessionLight`（每会话）就够。
26. 每会话一份：`View`、`SessionLight` 的 13 个字段、输入区草稿与历史、`cwd` / `home`、
    `files: FileIndex`（根 = 会话 cwd）、`catalog`（切焦点要重发）、`read_only`、
    `pending`（问卷 / 权限门，每份自带自己的 reply 通道）、`detail_opener` / `detail_rect` /
    `detail_serial`（今天不在 `SessionLight` 里，要搬进去）。
27. 全局一份：浮层本体（`detail` / `file_viewer` / `picker` / `notice` / `close_blocked`）、
    `regions` / `screen_text` / `drag`、`tab` / `sidebar_wanted` / 两个键盘归属、退出举手、
    `background_waiting` / `background_finished`、未读账（主循环一本，只写终端标题）。
28. `main_tab` 与主列页签条随票 12 整条删除；`CHROME` 6 → 6 由顶部条补回。

### F. 全屏唯一物

29. **输入区**全局一份、绑焦点格；**草稿与历史每会话各存**（沿用 `SessionLight::editor` 的
    stash / load）。
30. **状态行与提示行**全局一份、读焦点会话；状态行加全局读数「另有 N 个在跑 / M 个等人类」。
31. **问卷与权限门**：每会话一份 `pending`，全屏同一时刻只显示**焦点会话**那一份；**接管期间可以
    切焦点、题面跟着焦点走**。
32. **详情覆盖层与文件查看器**照旧整屏居中；记录「打开方」并按打开方还原；**已开着的覆盖层不因
    切焦点而换归属**。
33. **拖选**仍夹在按下那一刻所属的文本区域里，不跨格；OSC 52 与终端原生选择照旧。
34. **`Ctrl-C` 取消焦点格当前的动作**，永不退出；**退出举手仍是进程级一个**。
35. **终端标题写焦点会话**；顺手修掉 `SwitchSession` 不更新 `cwd` / `home` 那个既有缺陷。

### G. 顶部页签条与左栏会话页的分工

36. **顶部列宿主表、左栏列盘上会话**：两处数据源不同，只有「已装载的会话」同时出现。
    分工一句话：**顶部说「在不在屏上 / 是不是焦点」，左栏说「这个会话是什么状态」**。
37. 顶部标签只写**标题、焦点标记、集合成员标记**（外加右端的平铺按钮与右栏开关）。
    **状态类一个都不上标签**（忙 / 闲 / 等人类、未读、装载态都不上）；等人类由状态行的全局读数
    承担。
38. **未读不上标签**：维持既有唯一形态——终端标题状态段的 `N 场跑完`（票 11 / 25）。
39. 标签顺序 = **宿主表装载顺序**（稳定）；溢出收成 `+N` 靠右端、**不可点**；**顶部不做过滤**。
40. 标题与左栏同一份 `title_of` 字符串、同一套 `fit_title` 截断；**单个标签最多 24 列**；
    不写 `父/基名`（那是终端标题路径段的写法）。改名入口仍只在左栏会话页的 `r`。
41. 左栏会话行**一个字不改**：组头、标记列三态、标题、时间 / 损坏、`MUTED`、页顶读数 + 新建 / 关闭、
    末行 `＋N`、`/` 过滤、`r` 改名。

### H. 提示行

42. 判据从「页」改成**「键盘在谁手里」**：右栏拿住键盘时用 `RAIL_HINTS`，否则用 `KEY_HINTS`。
    平铺态不另开第三套（每格只有对话视图）。
43. `KEY_HINTS` 9 条：`enter 发送` / `ctrl-j 换行` / `esc 取消` / `shift+tab 模式` /
    `PgUp/PgDn 滚动` / `ctrl-t 换模型` / **`ctrl-v 右栏`** / **`ctrl-r 平铺`** / `ctrl-o 左栏`。
44. `TRACE_HINTS` 改名 **`RAIL_HINTS`**，条目照旧，`ctrl-v 对话` → **`ctrl-v 交还`**。
    `ctrl-1…4` 不进表（加速档，与 `g` / `G` 同类）。提示行宽度分档的断言按新条目重取实测值。

### I. 配置与 herdr

45. **`[ui] tile_limit`**：整数 `2..=4`，默认 `4`；上限 4 因为排法只到 4，下限 2 因为一个格会自动
    回标签态。**`[ui] sidebar`**：`auto` / `always` / `never`，默认 `auto`。两项与
    `number_style` / `file_viewer` 同一段；**非法值一律拒绝启动**并给中文错误消息。
46. **herdr**：判据 `HERDR_ENV == "1"` 精确等值；只在 `[ui] sidebar = auto` 时**读一次**（TUI 组装
    那一刻），plain 与 headless 不读；结果只当 `sidebar_wanted` 的**初值**，`Ctrl-O` 照旧改它、
    只活在进程内，**重启回到默认关**；读不到 / 非 `1` / 变量不存在 = **不在 herdr**（默认开左栏）。

### J. 状态读取与重放

47. **两态切换就是一次宽度变化**，走既有的宽度重放：对话视图按 `top_source` 保住顶端来源行、
    `follow` 贴底照旧；只清折行缓存重放那一侧。
48. **选中 / 过滤 / 折叠 / 搜索串按 `BlockId` 记**，宽度无关，原样保留；`trace-ledger` 的
    「认块不认位置」直接接上。
49. **容量不做懒算**：`painted` 每会话常驻；`Pane` 的折行缓存在 `view()` 时按需算，非焦点格不画就
    不算；`CAP = 20_000` 不动。实测真出内存问题再另开票。

### K. 术语、文档与 ADR

50. `CONTEXT.md` **新立五个**：右栏（`RightRail`）、顶部页签条（`TabStrip`）、平铺（tiles）、
    格（`Tile`）、焦点格（`FocusedTile`）；**改四个**：轨迹视图（住右栏、不再常驻主列）、
    对话视图（主列唯一一页）、左栏（删掉「轨迹在主列页签条上」两处）、前台（补一句平铺态下等于
    焦点格）。**「格」的 `_Avoid_`**：pane / 窗格（那是 `render::pane::Pane`：转录滚动缓冲）、
    分屏、面板。
51. **立两条 ADR**：0023「平铺的进程模型」（同进程多会话，不做多进程、不交给 herdr / tmux 的
    pane）与 0024「轨迹的落点（主列 → 右栏，第三版）」。**herdr 的检测与默认值不立 ADR**。
52. **`docs/render.md`**：改 `## 外壳`（6 行预算与分区）、`## 两个视图`（对话在主列、轨迹在右栏，
    删「永远可达」那段）、`## 时间轴`、`## 键盘`（`Ctrl-V` 与两套提示行）、`## 折叠与过滤` /
    `## 拖选与复制` / `## 可点链接`（「轨迹页」改「右栏」），并**新增「右栏」一节**。
    **`docs/tui-manual-checklist.md`** 加一条真机项（顶部页签条 / `Ctrl-R` / `Ctrl-1…4` / 右栏层序）。
    **`docs/lifecycle.md` 不动**（平铺不新增进程或事件）。

## 测试决定

**两个既有 seam，不新增**：

1. **帧断言**（`tests/render_layout.rs` 的既有装置：构造 `TuiState` → `layout::plan` → 渲染一屏 →
   断言屏幕文本）。外壳的所有几何与文字都在这里验收。
2. **pty 回归**（`tests/` 与 `scripts/tui-startup-check.py` 的既有装置：真进程、真按键）。两态切换、
   换焦点、右栏开关与真实多会话装载在这里验收。

**什么算好测试**：只断言外部行为——屏幕上的文本与行数、帧之间的差异、进程退出码；不断言内部字段、
不依赖 `at` 时间戳。每一条决定至少有一条帧或 pty 断言；**不用「加测试」三个字交差**。

**帧断言清单**：

- 标签态 120×40：顶部条 2 行、左栏 40 + 主列 50 + 右栏 28、底部三行只跨 pane 区。
- 平铺态 120×40：1 / 2 / 3 / 4 格四种排法、各格尺寸、`[+ 加入]` 格（n < 4 时）。
- 降级：80 列 / 94 列 / 60 列与 24 / 30 行下回标签态；平铺态左栏不画。
- 右栏：40 / 28 档轨迹形态（时刻、用量、组头、时间轴 Compact）；右栏隐藏时 `Ctrl-V` 的回执。
- 顶部条：`+N` 溢出、标签无状态字形、焦点与集合成员标记。
- 屏高 < 20 时顶部条收成 1 行。
- 状态行的全局读数「另有 N 个在跑 / M 个等人类」。

**pty 清单**：

- `Ctrl-R` 两态往返；`Ctrl-1…4` 换焦点；点格子换焦点。
- `[+ 加入]` 打开选择器并加入；`×` 移出；满员拒绝的回执。
- 只剩一个自动回标签态；`/clear` 后新会话接替旧位。
- `Ctrl-V` 开栏 + 交键盘、再按关闭 + 交还、点输入区交还但栏留着；`Esc` 层序。
- 平铺态按 `Ctrl-O` 给回执。
- `HERDR_ENV=1` + `auto` → 左栏不画、`Ctrl-O` 能叫回；未设 → 画；`always` / `never` 覆盖。
- 配置：`tile_limit` 的 2 / 4 合法、1 / 5 拒绝；`sidebar` 三个字面量合法、别的拒绝；错误消息对齐
  `number_style` 那条的测试写法。

**重放与视图状态**（可放帧缝或纯单测）：宽度从主列 50 变到格 45 再变回，`top_source` 保位；选中、
过滤、折叠按 `BlockId` 活过重放；轨迹在右栏两态切换**不重放**（缓存不动）。

**prior art**：`tests/render_layout.rs` 与 `tests/render_changes.rs` 的帧断言；`trace-ledger` 票 12
的宽度重放与身份测试；`session-tab` 的宿主表与装载测试；`scripts/tui-startup-check.py` 的 pty 冒烟；
`sidebar-toggle` 的宽度 × 意愿帧断言。

## 范围之外

- **多进程分屏 / 把分屏交给 herdr、tmux、zellij 的 pane**：冻结项 2 选了同进程 —— 进程间无法共享
  宿主表与团队通信。
- **herdr 的深层集成**：状态回传、CLI / socket API、把 heng 会话变成 herdr pane。**例外**：
  heng 侧的 herdr 自接入上报（`src/herdr.rs`）已在图外实现，见 [`docs/herdr.md`](../../docs/herdr.md)；
  它不属本 spec，也不受本 spec 约束。
- **`multi-role-view`（同一份流的多个发言人）**：另一张图。
- **团队视图的本体**（右栏第二页、信箱、任务板）：独立种子 `agent-teams`；本 spec 只保证右栏容器
  留得下。
- **超过 4 个格**，以及为「更多格」做虚拟化。
- **平铺态拖拽调整边界、双击标签、右键菜单**：排法定死，没有可拖的边界；`DRAG_THRESHOLD` 仍只分
  「点击 vs 拖选」。
- **右栏后续页面的本体**（团队、任务板、用量面板）。
- **图片与附件面**（`image-input` 那条 seed）。
- **`architecture-deepening` 的两条**（左栏四页成 module、`View` 是投影的 seam）：各自另开 effort。
