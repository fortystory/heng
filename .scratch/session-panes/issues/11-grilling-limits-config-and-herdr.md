# 上限、配置与 herdr 默认值的落点

## 问题

[herdr 的一手事实](03-research-herdr.md) 回来后，这一票把三条「默认值与配置」拍定：

1. **`[ui]` 里加什么**。平铺上限（默认 4）的项名与取值范围 —— 与 `number_style` / `file_viewer`
   同一段（`src/config.rs`）；非法值怎么处理，照现有 config 的惯例给「拒绝启动」还是「回落到默认」
   并说理由。
2. **超出上限的行为**。冻结项 3 已定**拒绝**：回执写在哪（提示行 / 状态行）、什么措辞 —— 措辞走
   `wording.rs` 那层，中文，与既有回执同一制式。
3. **herdr 的默认值**（冻结项 9）。`HERDR_ENV=1` 时左栏默认关：这个「默认」怎么与
   `sidebar-toggle` 的「意愿只活在进程内、宽度档相乘」合并；人在 herdr 里按 `Ctrl-O` 把左栏叫回来
   之后，重启 heng 是不是又回到关（要，还是不要）。**判据没有稳定性承诺**
   （[herdr 的一手事实](03-research-herdr.md) 第 1 条：官方承认、但没有一处承诺它稳定）：
   读不到 `HERDR_ENV` 就等于不在 herdr（默认开左栏），**检测失败不许反过来关掉人的左栏**。
   另：herdr 里 heng 看到的面板宽度已被扣掉一档（外层 120 → 94），所以「默认关」在多数终端上
   与宽度档的判断同向 —— 两条规则撞在一起时谁说话，也要拍。
4. **配置覆盖**。`[ui]` 那一项是三态（自动 / 强开 / 强关）还是布尔；名字与语义（「自动」= 看检测，
   其余给确定值）；写在 `docs/` 哪里。
5. **判据读几次**。检测在哪个时刻读（启动一次 / 每帧读环境）；`plain` 与 headless 两种渲染器下算
   不算（它们没有左栏，但共用 config 与启动路径）。
6. **测试**。`[ui]` 新项与检测怎么进现有 config 测试与 pty 回归（`tests/`），要给出可执行的那一档
   （不许只写「加测试」）。

## 作答

**（2026-10-17，一轮六问，维护者全部按推荐。此外票 05 交过来的「标签态越界」也在第 5 条落定。）**

**一句话：`[ui]` 加 `tile_limit`（2..=4，默认 4）与 `sidebar`（`auto` / `always` / `never`，
默认 `auto`）；herdr 只认 `HERDR_ENV == "1"`、只在 `auto` 下读一次；右栏档从 40 往下降，
取第一个让主列 ≥ `MIN_WIDTH`(40) 的档。**

### 1. `[ui]` 的两个新键

| 键 | 值 | 缺省 | 语义 |
| --- | --- | --- | --- |
| `tile_limit` | 整数 `2..=4` | `4` | 平铺集合上限；超出拒绝（冻结项 3） |
| `sidebar` | `auto` / `always` / `never` | `auto` | 左栏**启动初值**：`auto` 看 herdr，`always` 强开，`never` 强关（冻结项 9） |

落点是 `src/config.rs` 的 `UiSettings`（`config.rs:518`），与 `number_style` / `file_viewer`
同一段；解析与错误消息照 `config.rs:2478` 那组既有写法。

### 2. 值域与非法值

- `tile_limit` 取 **`2..=4`**：上限 4 因为排法只到 4（冻结项 4），下限 2 因为一个 pane 会
  自动回标签态（票 07）。默认 4。
- **非法值一律拒绝启动**（越界、非整数、未知的 `sidebar` 字面量），照 `number_style` 那条惯例
  给中文错误消息。不回落到默认 —— 静默改写人的配置比拒绝启动更难查。

### 3. 超出上限的回执

**提示行**（`hints`）一句：`平铺最多 {N} 个；先移出一个再加`，`N` 从配置读，措辞进
`src/render/wording.rs`，与既有回执同一制式。

### 4. herdr 的默认值

- 判据：**`HERDR_ENV == "1"` 精确等值**（票 03 第 1 条：官方承认，但没有稳定性承诺）。
  读不到 / 非 `1` / 变量不存在 = **不在 herdr** → 默认开左栏。
- 读的时刻：**只在 `[ui] sidebar = auto` 时读一次**，就在 TUI 组装那一刻；不每帧读、不落盘、
  不写配置。`plain` 与 `headless` **不读**（它们没有左栏）。
- 结果只当 `sidebar_wanted` 的**初值**（`tui.rs:2569`、`:3994`）：之后 `Ctrl-O` 照旧改它、
  **意愿只活在进程内**（`sidebar-toggle/spec.md` §1）；**重启回到 herdr 默认关**。
- 与宽度档的关系照旧**相乘**：`可见 = sidebar_wanted && sidebar_tier(width).is_some()`
  （`layout.rs:623-626`）。herdr 里 94 列落 28 档，两条规则同向，不打架 —— 只有 `always`
  能把意愿拉回 true，宽度不够仍然画不出来。
- **检测失败绝不反过来关掉人的左栏**。

### 5. 右栏让位阈值（票 05 交过来的那条越界）

- **标签态**：右栏档从 40 往下降（40 → 28 → 隐藏），取第一个能让主列 ≥ `MIN_WIDTH`(40) 的档；
  **左栏档照旧不动**（`sidebar_tier` 那一层不改）。
- **平铺态**：左栏已收起（票 09），判据换成「pane 区宽 ≥ 32 × 列数 + 间隔」（票 08 的 32 列下限）。
- 具体数字：**120 列两侧栏同时开 → 右栏 28 档、主列 50**；**≥ 122 列**右栏才是 40 档；
  **< 98 列**右栏隐藏（左栏在 28 档时）。
- 这条给票 10 的 `trace_width`（右栏内宽）一个确定的来源：轨迹宽度 = 右栏档 − 内边距。

### 6. 测试（可执行的那一档）

- **config 单测**：`tile_limit` 的 2 / 4 合法、1 / 5 拒绝；`sidebar` 三个字面量合法、别的拒绝；
  错误消息逐字对齐 `number_style` 那条的测试写法。
- **pty 回归**（`tests/`）：`HERDR_ENV=1` + `auto` → 左栏不画、`Ctrl-O` 能叫回；未设 + `auto`
  → 画；`HERDR_ENV=1` + `always` → 画；`never` → 不画。
- **帧断言**：120×40 两侧栏同时开 → 右栏 28 档且主列 ≥ 40；94×40 平铺 4 个 → 每格 ≥ 32×10
  （票 08 的判据）。

  加一条 herdr 真机项（`HERDR_ENV=1` 下左栏默认关、`Ctrl-O` 叫回、重启回关）。
- **herdr 认不出 heng 这件事不在本图**：票 03 的结论是 `lookup_agent` 的精确等值表里没有
  `heng`，heng 侧不做任何事；本图的范围之外也写着「herdr 的深层集成不做」。
