# 全屏唯一的东西在平铺下怎么活

Type: grilling
Status: resolved
Part of: ../map.md
Blocked by: 01, 02

## 问题

[视图外壳与键盘](02-research-view-shell-and-keys.md) 会把「全屏唯一物」列成一张表。这一票逐条拍下
它们在平铺态里的归属 —— 每条都要落成一个能在 spec 里执行的句子：

1. **输入区**（冻结项 8 已定底部全局一份、绑焦点 pane）：草稿归谁？焦点一切换，草稿跟着走还是各存
   一份？`/` 与 `@` 浮层、记号菜单跟着谁？
2. **状态行与提示行**：全局一份（读焦点会话）还是每 pane 一份？忙闲、目标名、Token 数、模式那一格
   读谁？提示行在平铺态要不要换一套（与
   [平铺的手势与焦点](07-grilling-pane-gestures-and-focus.md) 相接）。
3. **问卷与权限门**：它们本质上是「某个会话在等人」。平铺时提问从哪冒出来 —— 就地画在那格、还是
   照今天的形态全屏接管？焦点自动跳过去吗？回答之后焦点回哪？
4. **详情覆盖层与文件查看器**：今天全屏居中（`detail_width` 按**整屏**算）。平铺时开在 pane 内还是
   仍旧全屏？关掉还原给谁（今天的规则是「还原给打开它的那一页」）。
5. **拖选与剪贴板**：文本区域今天是「落点最上层那一块」，选区夹在那一块里。pane 边界会不会切断
   一次拖选；覆盖层立着时还能不能选。
6. **退出举手与 `Ctrl-C`**：举手是全局一个还是每会话一个；`Ctrl-C` 今天只取消前台那个会话
   （`session-tab` 票 23 特意拆掉的旧语义），平铺后是取消焦点 pane 还是全部。
7. **终端标题**：`<父>/<基名> · <状态> · <目标名>` 今天跟谁走；平铺里有四个会话在跑，写谁。

## 作答

**（2026-10-17，两轮 grilling 共十问。判据 = [视图外壳与键盘](02-research-view-shell-and-keys.md)
的「全屏唯一物 × 归属改造」表 + [宿主表与多会话基础设施](01-research-session-infrastructure.md)
的底账。）**

**一句话：全屏唯一物在平铺态分三档 —— ①读焦点（输入区、状态行、提示行、终端标题）；②绑发起
会话、全屏接管（问卷、权限门、详情覆盖层、文件查看器）；③本来就只能一份（拖选、举手、剪贴板）。**

1. **输入区**：全局一份、绑焦点；**草稿每会话各存自己的**（沿用 `SessionLight::editor` 的
   stash / load，`tui.rs:9642` / `:4250`），切焦点只换显示。`/` 与 `@` 浮层跟着输入区走。
2. **状态行与提示行**：两条都**全局一份、读焦点会话**，并**在状态行加一段全局读数**「另有 N 个
   在跑 / M 个等人类」—— `background_waiting` / `background_finished`（`tui.rs:2528`）本来就是
   这一档读数。帧 05 画的正是这一种。
3. **问卷与权限门**：**全屏接管、焦点自动跳过去**；而**接管期间可以切焦点、题面跟着焦点会话走**。
   这一条**推翻了本票最初的设想**（也是票 02 表里那句初判）：结构上 `TuiState.pending`
   （`tui.rs:2678`）要从**单例**改成**每会话一份**（每份自带自己的 reply 通道 —— reply 唯一这
   件事不变），全屏同一时刻只显示**焦点会话**的那一份，其余等待中的会话由第 2 条那句全局读数点名。
   票 02 的作答里已留校订行。
4. **详情覆盖层与文件查看器**：照旧**整屏居中**（`detail_width` 对着整屏量，不缩进 pane —— 缩进会
   让正文排版宽度全变）；**记录「打开方」**（今天 `detail_opener` 的语义直接扩展）：右栏里开的
   还原给右栏，某个 pane 里开的还原给那个 pane；**已开着的覆盖层不因切焦点而换归属**。
5. **拖选**：仍**夹在按下那一刻所属的文本区域里**（今天 `selection` 的规则），pane 边界天然切断；
   **跨 pane 拖选不做**。OSC 52 与终端原生选择照旧。
6. **`Ctrl-C` 与退出举手**：`Ctrl-C` 取消**焦点 pane** 的当前动作（沿用票 23 拆掉「第二下变退出」
   之后那条语义：取消只沿委派链向下）；**退出举手仍是进程级一个**（一次进程只退一次）。
7. **终端标题**：写**焦点会话**；顺手修掉票 01 报的 `TuiState.cwd` / `home` 不跟 `SwitchSession`
   走那个缺陷（今天切到别 cwd 的会话后，标题与 `@` 候选还是旧的）。

**交给别人的**：焦点怎么移动、平铺集合的生灭 → [平铺的手势与焦点](07-grilling-pane-gestures-and-focus.md)；
右栏那一层自己的键盘 → [右栏的键盘与页面容器](08-grilling-right-rail-keyboard.md)；
页签条上怎么写状态 → [顶部页签条与左栏会话页的分工](09-grilling-tab-strip-and-session-page.md)；
完整归属表 → [每会话的视图状态与两态切换](10-grilling-per-session-view-state.md)。
