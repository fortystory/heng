# 24: 重放保真

Type: implement
Status: ready-for-agent
Part of: ../map.md
Blocked by: 23

**要建的：** 宽度变化之后，阅读位置与选择不丢。

- 两态切换就是一次宽度变化：对话视图按 **`top_source`** 保住顶端来源行，`follow` 贴底照旧；
  只清折行缓存、重放那一侧。
- **选中 / 过滤 / 折叠 / 搜索串按 `BlockId` 记**，宽度无关，原样保留；「认块不认位置」直接接上。
- **轨迹在右栏：两态切换不重放**（右栏宽度由屏幕宽度档决定，与两态无关）；只有屏幕宽度跨档才
  重放。
- `CAP = 20_000` 不动；不做懒算。

## 验收

- [ ] 主列宽度 50 → 45 → 50：顶端来源行不变（帧）。
- [ ] 切平铺再切回：选中的块仍是同一块、过滤与折叠仍在（帧 / 单元）。
- [ ] 标签态 ⇄ 平铺态来回切时右栏轨迹缓存不重建（帧文本一致，且无重放路径）。
- [ ] 屏幕宽度跨右栏档（如 119 → 122）时轨迹重放一次且只一次。
- [ ] 既有的宽度重放测试全绿。
