# 24: 重放保真

Type: implement
Status: done
Part of: ../map.md
Blocked by: 23

**要建的：** 宽度变化之后，阅读位置与选择不丢。

- 两态切换就是一次宽度变化：对话视图按 **`top_source`** 保住顶端来源行，`follow` 贴底照旧；
  只清折行缓存、重放那一侧。
- **选中 / 过滤 / 折叠 / 搜索串按 `BlockId` 记**，宽度无关，原样保留；「认块不认位置」直接接上。
- **轨迹在右栏：两态切换不重放**（右栏宽度由屏幕宽度档决定，与两态无关）；只有屏幕宽度跨档才
  重放。
- `CAP = 20_000` 不动；不做懒算。
