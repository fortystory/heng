# 15: 顶部页签条

Type: implement
Status: done
Part of: ../map.md
Blocked by: 14

**要建的：** 屏幕最上面出现**顶部页签条**：它列**宿主表**（这个进程里活着的会话），只管显示。

- 占 2 行、**横跨整屏**：标签行 + 一条虚线。**屏高 < 20 时收成 1 行、不画虚线**。
- 每个标签只写：**标题、焦点标记、集合成员标记**。**状态类一个都不上标签**（忙 / 闲 / 等人类、
  未读、装载色都不上）；等人类由状态行承担（票 21）。
- 右端放**平铺按钮**与**右栏开关**。
- 标签顺序 = **宿主表装载顺序**（稳定）；放不下时收成 **`+N` 靠右端、不可点**。
- **左栏顶部下移 2 行**：身份行与 3 行左栏页签条从顶部条之下开始。
