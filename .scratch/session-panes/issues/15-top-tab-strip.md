# 15: 顶部页签条

Type: implement
Status: ready-for-agent
Part of: ../map.md
Blocked by: 14

**要建的：** 屏幕最上面出现**顶部页签条**：它列**宿主表**（这个进程里活着的会话），只管显示。

- 占 2 行、**横跨整屏**：标签行 + 一条虚线。**屏高 < 20 时收成 1 行、不画虚线**。
- 每个标签只写：**标题、焦点标记、集合成员标记**。**状态类一个都不上标签**（忙 / 闲 / 等人类、
  未读、装载色都不上）；等人类由状态行承担（票 21）。
- 右端放**平铺按钮**与**右栏开关**。
- 标签顺序 = **宿主表装载顺序**（稳定）；放不下时收成 **`+N` 靠右端、不可点**。
- **左栏顶部下移 2 行**：身份行与 3 行左栏页签条从顶部条之下开始。

## 验收

- [ ] 120×40 帧：第 0 行标签、第 1 行虚线；左栏的身份与页签条从第 2 行起；右栏从第 2 行起。
- [ ] 标签内容只有标题 + 焦点 + 集合成员；加一个正在跑的会话**不会**让标签多任何状态字形。
- [ ] 3 个以上会话超出可用宽度时出现 `+N`，贴右端；`+N` 点击无效。
- [ ] 19 行高的帧：顶部只有 1 行、没有虚线。
- [ ] 至少 4 条新的帧断言，`cargo test` 全绿。
