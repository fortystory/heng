# 18: 平铺集合与焦点手势

Type: implement
Status: done
Part of: ../map.md
Blocked by: 17

**要建的：** 平铺集合能加、能移、能换焦点。

- 集合是 `Vec<SessionId>`：有序、按加入顺序、**不允许重复**。
- **`[+ 加入]` 格参与布局**：集合 n 个时按 n + 1 格排；点它打开会话选择器（复用 picker 通道）。
- **移出**：焦点格标题行的 `×`。
- **换焦点**：`Ctrl-1`…`Ctrl-4` 直接跳第 N 格；鼠标点格子。
- 三条边界：**集合为空**时进平铺自动把焦点加入；**集合非空而焦点不在里面**时拒绝进平铺并提示；
  **只剩一个**时自动回标签态。

## 验收

- [x] 点 `[+ 加入]` 选一个会话后格数 +1、焦点不变；集合 4 个时该格不画。
- [x] 点焦点格 `×` 后格数 -1、焦点给集合里的下一个。
- [x] `Ctrl-1…4` 后焦点格的 `◆` 移到第 N 格（帧）。
- [x] 空集合时按 `Ctrl-R` 自动加入焦点进平铺（pty）。
- [x] 焦点不在集合时按 `Ctrl-R` 被拒绝并提示（pty）。
- [x] 移出到只剩一个时自动回标签态（pty）。

## 落地注记（2026-10-17）

- **`[+ 加入]` 复用既有的选择器浮层与键位**：候选 = 宿主表 − 平铺集合；`tile_picker` 记着
  候选 id，回车 / 点击选中之后直接进集合，**不进循环**（加入集合是纯前端的事，所以 reply
  那一端丢在装配处）。
- **移出**：焦点格标题行末尾一个 `×`；移出后「焦点给集合里的下一个」是一条上行的
  `OpenSession` —— 前台指针归循环，渲染层改不了。只剩一个时自动回标签态。
- **换焦点**：`Ctrl-1…4`（`Key::CtrlDigit`）与鼠标点格都发 `OpenSession`；平铺态换焦点不动
  几何。测试里用一次模拟的 `SwitchSession` 补上循环那一步。
- 边界三条全在：空集合自动加焦点、焦点不在集合拒绝并回执、移出到只剩一个回标签。
- 测试：`render_layout` 6 条（加号 +1、移出收窄、Ctrl-2、空集合、拒绝、加人后焦点不变）。
- 审查后修的边界：移出到**只剩一个**时不只是回标签态，**焦点也给剩下的那一个**（上行
  `OpenSession`）—— `removing_until_one_left_hands_the_focus_to_the_survivor` 钉住。
- `Ctrl-1…4` 只在平铺态是手势（标签态按下去什么都不发生，`ctrl_digits_only_work_in_the_tiled_state`）。
