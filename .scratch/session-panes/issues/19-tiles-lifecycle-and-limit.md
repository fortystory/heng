# 19: 集合生灭与满员拒绝

Type: implement
Status: ready-for-agent
Part of: ../map.md
Blocked by: 18

**要建的：** 会话生灭时集合与焦点跟着走，满员时明确拒绝。

- **满员再加**（集合已有 4 个）：拒绝，提示行一句 `平铺最多 {N} 个；先移出一个再加`（`N` 后来从
  配置读，见票 26；本票先写死 4）。
- **关闭**一个会话：从集合移出，焦点给集合里的下一个。
- **新开 / 装载**一个会话：**自动加入**集合末尾。
- **`/clear` 翻页**：新会话**接替**旧会话在集合里的位置（不挪到末尾）。

## 验收

- [ ] 集合满 4 个时点 `[+ 加入]` → 不增加格子、提示行给回执。
- [ ] 关闭一个格子的会话 → 该格消失、焦点落到下一个（pty）。
- [ ] 新开 / 装载 → 新会话出现在集合末尾并成为焦点（pty）。
- [ ] `/clear` 后新会话占据旧位置（帧/pty）。
- [ ] 逐步收窄到只剩一个 → 自动回标签态。
