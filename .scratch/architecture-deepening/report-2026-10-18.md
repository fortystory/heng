## 候选项（按推荐强度）

### Strong · 把键盘归属收到一处

**模块**：`src/render/tui.rs`。**接口**：`key()`（L7593–L8599，1006 行，11 段早期 return）。
**Friction**：`key()` 的 11 段早期 return 已经是「按层持有」的事实，但每加一层就改一遍这 11 段；
`trace_keyboard` 的注释（`tui.rs:2639`）自陈「仓库里**第四套**「键盘在谁那里」的机制」（之前三套：左栏布尔、两页焦点索引、问卷反显）。`click_at` / `wheel_at` / `keyboard_in_the_input` 各持一份字段子集 —— 同一真相三处拼。
**Seam**：「层」。每层自己声明 `owns_keyboard()` 与 `handle_key()`；`sync_keyboard_owner()` 一处算。
**先例**：[ADR 0010](docs/adr/0010-questionnaire-keys-dispatch-by-zone.md)（问卷的「按区分发」）。
**测试**：键盘归属 bug 集中在一处，三入口（键、鼠、滚轮）共用一张 dispatch 表。

### Strong · 同一会话状态收到一处

**模块**：`src/render/tui.rs`。**接口**：`View`（57 字段）+ `SessionLight`（18 字段）+ `TuiState` 上
5 份按 `SessionId` 平行的 `HashMap`。
**Friction**：session-panes 票 23 / 25 落地后，`TuiState` 多出 `views` / `states` / `light` /
`catalogs` / `read_only_by` 五张表。每加一会话属性要改 ≥2 处。`stash_light` / `load_light`
（`tui.rs:4393/4421`）仍是手写搬运清单。
**Seam**：「一个会话的投影」。`SessionProjection` module 把 `View` 与 `SessionLight` 收一起，
`TuiState` 仅持 `HashMap<SessionId, SessionProjection>`；`stash` / `load` 收成一份迁移函数。
**测试**：会话字段增减只动一个 module；5 张 HashMap 收成 1 张。

### Worth exploring · host → cli → tui 的事实投影只算一处

**模块**：`src/cli/interactive.rs` + `src/render/input.rs` + `src/render/tui.rs`。
**接口**：`ConsoleHandle`（`src/render/input.rs:311`，12+ 个 `pub fn`）+ `ConsoleRequest`（22 个变体）。
**Friction**：「宿主表现在长什么样」算成三处 —— `cli/interactive.rs:572` 的 80ms 轮询算上一帧快照、
`ConsoleHandle` 12+ 推命令、`TuiState` 各会话一份快照。10-12 那条「宿主表的投影只算一处」升级而成。
渲染层要认的领域事实从 6 种涨到 10+ 种，每种一条 push 命令。
**Seam**：`HostFacts` module 同时被 cli 与 tui 订阅；三条规则（未读的寿命、`N` 只算后台、单会话
标题不变）落到单元测试 —— 现在只能走真机走查
（[`tui-manual-checklist.md` ㊶](docs/tui-manual-checklist.md)）。
**注意**：与「单会话」默认行为耦合；先把「宿主表空 / 单会话 / 多会话」三态的读数在 spec 里钉死，
再改订阅。

### Worth exploring · width module 的 seam 收齐

**模块**：`src/render/width.rs`（97 行）。
**接口**：`truncate_columns` / `ellipsize_line` / `slice_columns`。
**Friction**：上层（panel / todo / trace）已走 `width::truncate_columns`，下层仍按 `chars().take` 拼：
`transcript.rs:663`、`wording.rs:222` / `:963`、`changes.rs:589`、`files.rs:118`、`tui.rs:15059`
（10-18 新发现）。`markdown::wrap_code` 按列自折一份。
**Seam**：把 6 处 `chars().take` 一律改成 `width::truncate_columns`；带样式的改 `width::ellipsize_line`。
与 [ADR 0008](docs/adr/0008-markdown-parsing-by-pulldown-cmark.md)（「换行归我们」）同向，没走完。

session-panes commit 后从「形态问题」升到「架构问题」，再不收，第五套（平铺态里「焦点格持键盘」）

收益跨三入口（键、鼠、滚轮）。

width 半截收与 host 事实投影排在更后。
