# 09: 会话的量词从「场」换成「会话」

Type: implement
Status: done
Blocked by: 01
Part of: ../spec.md

**要打通的行为**：界面、注释、文档里不再用「场」作会话的量词 —— 统一说「**会话**」，宿主表
读数说「已装载 N 个 · M 个在跑」。

**来源**：2026-10-12 维护者在 [票 32](../session-tab/issues/32-close-interaction.md) 的访谈里
（Q13–Q19）要求淘汰这个量词。这不是措辞偏好：那个量词一直在承担「盘上的会话（store）」与
「进程里活着的会话（宿主表）」两个数的区分，换代之后读数要换说法把这件事补回来。

## 范围（档 2）

**改**：

- `src/` —— 用户可见文案**与代码注释**（`cli.rs` 158、`tui.rs` 140、`lib.rs` 81、`wording.rs`
  64、`host.rs` 50 处集中在这些文件）
- `CONTEXT.md` —— 词条正文里的量词与指代
- `docs/`
- 活跃的 `spec.md` / `map.md`
- `tests/` 里的断言

**不改**：已关闭的历史票（`.scratch/**/issues/`）与 `docs/adr/` —— 那是记录，改了就失真。

**例外**（按原义保留或另行替换）：

- `场外` → **`后台`**，词条名同改「后台通知」（前台 / 后台本来就是一对）
- `一场讨论` → **`一次讨论`**（与「一次运行」「一次调用」同族）
- `开场` / `清场` 这类固定搭配**保留** —— `清场` 是 `/clear` 回执里的动作名，不是计数用法

## 实现记录（2026-10-12）

**改了 63 个文件、约 1,200 处**，全部机械替换 + 逐处核对：

- `src/` 727 处（`cli.rs` / `tui.rs` / `lib.rs` / `wording.rs` / `host.rs` 最集中）、`tests/` 214 处、
  `docs/` 163 处、`CONTEXT.md` 40 处、本 feature 的 `spec.md` / `map.md` 93 处。
- 三类例外按票面处理：`场外` → `后台`（含词条名）、`一场讨论` → `一次讨论`、`开场` / `清场` /
  `现场` / `立场` / `退场` / `当场` / `在场` / `场景` / `场合` 一律不动。
- **护栏**：`scripts/check-language.py` 多一条 `check_noun_discipline()`（禁用搭配清单），红 → 绿
  走的就是这一轮；带引号的「场」（讨论这个词本身）与 `docs/adr/` 豁免。
- **两处宽度后果**（票面要求的「预算重算」）：`session_count` 加 `wide` 参数 —— 窄档放不下
  「已装载」那三个字，会挤掉同一行右端的 `新建` / `关闭`；`＋N 个会话` 比 `＋N 场` 长但末行
  是整行，放得下。终端标题那两段反而短了 2 列。
- **顺带修掉迁移带出的一个 bug**：`＋{missing} 场` 的规则替换写成了 `＋＋{missing} 个会话`
  （原有的 `＋` 加新加的 `＋`），并由新增的窄档断言之外的一条既有测试（末行读数）兜住。
- README 的 ADR 索引入口让它越过字符棘轮，按仓库惯例**显式上调** `19,800 → 19,950`（终点
  18,500 不变），记录写在 `scripts/check-doc-size.py` 里。

### `/code-review` 抓到的东西（已修）

Standards 轴一眼看出机械替换的两处系统性错误 —— 护栏只守「场」字回潮，对它们完全无感：

- **讨论的量词被顺手改了**：`起一个会话多角色讨论`、`## 跑一个会话`（`docs/discussion.md`
  那一节讲的是 `heng discuss`）、`重放那个会话辩论`、`第二个会话的作答` —— 规则表只覆盖了
  「一场讨论」这种紧邻写法，其它变体落进了兜底。改成 `一次 / 那次 / 哪次 / 跑一次`。
- **`一个会话 X 会话` 的重复病句 23 个文件**：`组装一个会话单 agent 会话`、
  `装载一个会话磁盘上的会话`、`一个会话活着的会话`、`加载一个会话**空**会话`…… 根因是兜底规则
  `一场 → 一个会话` 撞上了原句里已有的「会话」。规则改成「后面 10 字内还有『会话』时只补
  『一个』」，残余的 3 处手工修掉。
- **读数口径三处不一致**：`docs/tui-manual-checklist.md` 两行与 `CONTEXT.md` 的空宿主条当时
  写成了 `1 个会话 · 0 个在跑` / `0 个会话` —— 统一到 `已装载 N 个 · M 个在跑`。
- 顺带：`cli.rs` 里那句「没有会话了」曾与 `wording::no_sessions_left()` 各写一份且已经不一致，
  统一到函数；护栏 docstring 的固定词表补上 `进场 / 收场 / 场合`。

Spec 轴又补了四处漏网，其中一条是**护栏假绿**：

- `tests/discussion.rs` 里有「第二场合成的材料」漏了 —— 护栏的 patterns 只列了 `两场`，没有
  `二场` / `第 N 场`，于是它自报 OK。patterns 补 `[一二三四五六七八九十]场`。
- `README.md` / `AGENTS.md` / `.scratch/README.md` **在档 2 之外**（原来的 scope 只写了 `docs/`）：
  README 里「续指定的一场」「起一场多角色讨论」「眼前这一场」都没迁。补迁，护栏 scope 也带上
  这三个文件。
- `wording::new_session_opened()` 丢了名词：「新开一个；…」→「新开一个会话；…」（用户可见）。
- 走查清单那行写 `已装载 1 个 · 0 个在跑`，而实现里 `running == 0` 时只报 `已装载 1 个` ——
  手工步骤与冻结口径对齐。
