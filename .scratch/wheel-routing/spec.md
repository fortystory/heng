# 滚轮归属：指针落在哪一栏，就滚哪一栏

Status: 8/8 done（01 是 triage 产出的契约票，02–08 全部落地）

- **来源**：2026-10-20 维护者报告「左栏的 `文件` 与中间的 `会话` 能滚，左栏的 `会话列表` 与右栏的
  `轨迹` 不能滚」，要求统一成「鼠标在哪个窗口上面就滚动哪个窗口」。同日一轮 grilling 定下判据、

## 问题陈述

滚轮只有一个入口：`TuiState::mouse` → `wheel_at` → `keyboard::wheel_dispatch`，反向过七层。
今天只有两处认领这一下：

| 指针位置 | 谁认领 | 实际行为 |
| --- | --- | --- |
| 左栏 `文件` | `SidebarLayer` | 滚这一页，每格 1 行 |
| 左栏 `改动` | `SidebarLayer` | 归它、不动（有意） |
| 左栏 `会话` / `调用量` / `todo` | 无人 | 落到 `InputLayer` 兜底，**滚主列对话视图** |
| 右栏 `轨迹` | 无人（`TraceLayer` 没有 `handle_wheel`） | 同样穿透，**滚主列** |
| 右栏 `流程` | 无人 | 同样穿透，滚主列 |
| 主列对话视图 | `InputLayer` 兜底 | 滚自己，每格 3 行 |
| 详情覆盖层 / 文件查看器 / 问卷 | 各自规则 | 详情不看坐标全吃；查看器全吃；问卷只看自己那块区域 |

会话页没有视口字段，溢出只画到页高、末行折成 `＋N 个会话`。轨迹页有窗格却没有 `handle_wheel`。
其余页连视口都没有。所以「不能滚」不是滚轮没送到，是那里没有可滚的东西。

## 决定

### §1 判据：指针落在哪个滚轮目标上，就滚哪个滚轮目标

滚轮目标从内到外四档：**浮层 → 格（平铺态）→ 栏（左栏 / 主列 / 右栏）→ 无**。

- 浮层悬在栏之上：指针在浮层矩形里就归浮层。
- 平铺态里每格是一个滚轮目标：指针在哪格就滚哪格。
- 栏内的**页签条与空白**算该栏（左栏页签条、右栏页签条都是）。
- 输入区、提示行、状态行、回合条这些「没有视口的地方」滚轮**无动作**（今天它们兜底去滚主列，
  这一条改掉）。
- 栏不在屏上（左栏收起、右栏隐藏、窄到画不下、平铺态没有左栏）时，那一栏不是滚轮目标 ——
  指针所在的下一层接。

### §2 每个滚轮目标都有视口

- **左栏五页**：会话、调用量、todo、文件、改动各有一份视口（文件页已有）。内容装得下时滚轮
  归它但不动；装不下时滚。
- **主列**：标签态是焦点会话的对话视图；平铺态是每一格各自的对话视图（`views` 表里每会话一份）。
- **右栏两页**：轨迹滚自己的 `Pane`；流程页给它视口（内容通常装得下，装不下时滚）。
- **浮层**：模型选择器与 `/`、`@` 候选菜单的滚轮**移动高亮**（与问卷的滚轮同一条语义）；
  详情覆盖层「框内滚自己、框外滚下面那栏」；问卷与中间模态保持今天的样子。

### §3 步长：列表页 1 行、正文页 3 行

- 列表页（左栏会话 / 文件 / 改动 / todo）、流程页：一格 1 行。
- 正文页（主列对话视图、右栏轨迹）：一格 3 行（`pane::WHEEL_ROWS`），与今天对话视图一致。
- 文件页的 1 行不变。

### §4 溢出读数退场

有了视口之后，三处「还有多少」的末行退场：会话页 `＋N 个会话`、todo 页 `＋N 项`、改动页
`还有 M 处改动`。不另加总数字读数（会话页页顶的 `已装载 N 个` 是宿主表读数，与列表条数无关，
不动）。

### §5 滚动条：只在滚动时出现

- 每栏与平铺态**每一格**的内容区右缘**一列**画一条**只有滑块**的滚动条（`█`、`MUTED`；视口
  不在底部时 `BOLD`），不画轨道与箭头 —— 与主列今天那条同形（格内也画，2026-10-20 维护者定）。
- **只在滚动时出现**：该栏最后一次滚轮在 1 秒内才画，过了就消失。时间由既有的 60ms 脉冲
  推进（`TuiState::tick`），不另起时钟。
- **出现与消失不得引起重排**：主列的转录早就为它留过列（`TRAILING_COLUMNS`），用那一列；
  左栏、右栏与平铺格都没有预留，就画在内容区最右一列上（覆盖 1 秒），不改内容宽度 —— 左栏
  各页与轨迹都是单行截断，格更窄，覆盖的代价小于改宽度档。主列那条也从「常驻」改成同样的
  「滚动时出现」。
- **滑块位置自己算，不用 ratatui 的 `Scrollbar`**（2026-10-20 维护者报的真机缺陷：内容贴底时
  滑块停在轨道中段）。上游那条公式的分母是 `content_length − 1 + viewport_length`，把
  `position` 取到 `total − height` 也到不了轨底 —— 内容越短偏得越明显（100 行 / 40 行视口 /
  40 格轨道时，滑块落在 17..29，而轨底是 40）。按下面这条算术画：
  - `v` = 视口行数，`n` = 总行数，`d = n − v`；`d == 0` 不画。
  - 滑块长 `l = max(1, round(track × v / n))`。
  - 起点 `s = round(top × (track − l) / d)`。于是 `top = 0` 时 `s = 0`、`top = d`（贴底）时
    `s = track − l`，中间线性。用整数运算，不引浮点。
- 滚动条不可点、不进命中表、不产生过滤。

### §6 滚轮不动焦点、不动选中、不拿键盘

滚轮是纯阅读手势：

- 会话页滚轮只动视口，不动焦点行；键盘 `↑` / `↓` 移焦点时视口跟着把焦点行带进来（与文件页
  `files_scroll_to_focus` 同一条判据）。
- 改动页同样：滚轮不动焦点，键盘移焦点时视口跟随。
- 轨迹页滚轮只动视口，不动块选中、不拿键盘（点账本拿键盘那条不变）。
- 平铺态滚非焦点格不换前台。
- 记号菜单与选择器的滚轮「移动高亮」是这条的例外：那两处的高亮就是「选中」，与问卷同一条。

### §7 不做

- **键盘归属一个字节不动**：`PgUp` / `PgDn` / `Ctrl-G` 仍归输入区（于是仍滚主列），本次只加滚轮。
- **文件查看器全吃指针不动**：它是一块外来的屏幕，`viewer_mouse` 把滚轮映射成 nvim 的 64/65 键。
- **不回退滚轮捕获**、不改终端鼠标协议。

## 测试决定

- 改写 [`tests/render_layout.rs`](../../tests/render_layout.rs) 的
  `the_wheel_over_the_sidebar_goes_to_the_conversation_when_the_trace_page_is_hidden`：它钉的正是
  被推翻的行为，换成「调用量页上的滚轮不滚主列」。
- 新增按坐标的用例：左栏会话页 / 改动页 / todo 页滚自己且主列不动；右栏轨迹滚自己且主列与选中
  不动；流程页不穿透；平铺态非焦点格滚自己且前台不变；输入区上滚无动作；页签条归栏。
- 会话页与改动页：滚轮不动焦点、键盘移焦点时视口跟随；溢出末行不再出现。
- 滚动条：滚动时出现、`tick` 推过 1 秒后消失；主列同样；左栏与右栏各一条。滚动条的绘制不改
  任何内容宽度（用同一帧的宽度口径断言）。
- 滑块位置：顶部 `s = 0`、贴底 `s = track − thumb` 两条边界各一条用例；再取一档「内容只比
  视口多几行」的短内容 —— ratatui 旧公式在那里偏得最厉害（贴底时滑块停在中段）。
- 记号菜单与选择器：滚轮挪高亮。
- 详情覆盖层：框内滚详情、框外滚下面那一栏。
- 既有滚轮用例逐条复核：问卷里的两条、文件页那条（`the_wheel_over_the_files_page_scrolls_the_tree`）、
  对话视图那条（每格 3 行）都应原样通过。

## 明确不做

- 键盘翻页键的归属（见 §7）。
- 顶部页签条（`TabStrip`）上的滚轮：它不是滚轮目标，落在它上面无动作。
- 历史重放（`replay`）期间的一切指针：照旧忽略。
