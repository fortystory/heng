# 02: 滚轮按滚轮目标归栏

Type: implement
Status: done
Blocked by: —
Part of: ../spec.md

**What to build:** 滚轮不再穿透到主列。指针落在哪个**滚轮目标**上就归哪个滚轮目标，滚轮目标从内到外是
**浮层 → 平铺格 → 栏**（左栏 / 主列 / 右栏）；栏内页签条与空白算该栏。落在没有视口的地方
（输入区、提示行、状态行、回合条、顶部页签条）**无动作**。栏不在屏幕上时（左栏收起、右栏隐藏、
窄到画不下、平铺态没有左栏）指针所在的下一层接。

本票只铺**判据**：左栏与右栏的页在这一步还不滚（后续票给视口），但主列不再被误滚。判据按
「上一帧真的画了什么」认领，收在各层 `handle_wheel` 里，不在 `mouse` 里另开一张坐标阶梯。

- [x] 指针在左栏任一页、右栏任一页上滚：主列对话视图**不动**（今天两者都会滚主列）。
- [x] 指针在主列对话视图（含滚动条列与回合条）上滚：仍滚主列，每格 3 行不变。
- [x] 指针在输入区、提示行、状态行、顶部页签条上滚：屏幕上任何一栏都不动。
- [x] 指针在左栏页签条、右栏页签条上滚：归对应栏（本票内表现为不动，且主列不动）。
- [x] 左栏收起、右栏隐藏时，指针在原位置滚：落到主列。
