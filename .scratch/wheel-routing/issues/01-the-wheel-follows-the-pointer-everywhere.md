# 滚轮跟着指针走：每一栏、每一页、每一个浮层

Type: implement
Status: done

> *This was generated by AI during triage.*

> 规格：`.scratch/wheel-routing/spec.md`。本票是给 AFK agent 的契约；规格里那几条「推翻了谁」
> 是背景，行为以本票为准。

**Category:** enhancement
**Summary:** 滚轮按指针位置分派到浮层 / 平铺格 / 左栏 / 主列 / 右栏，并给每一页补上视口与
「只在滚动时出现」的滚动条；滚轮永不穿透到别的滚轮目标。

**Current behavior:**

滚轮只有一个入口（`TuiState::mouse` → `wheel_at` → `keyboard::wheel_dispatch`，反向过七层
`KeyboardLayer`）。今天只有左右两处认领：左栏 `文件` 页滚自己（每格 1 行），左栏 `改动` 页被
认领但不动。其余滚轮目标**全部穿透**到 `InputLayer` 的兜底 `wheel_current`，滚的是主列对话视图
（每格 3 行）：

- 左栏 `会话` / `调用量` / `todo` 页 → 穿透，滚主列；
- 右栏 `轨迹` 页 → 穿透，滚主列（`TraceLayer` 没有实现 `handle_wheel`）；
- 右栏 `流程` 页 → 穿透，滚主列；
- 输入区 / 提示行 / 状态行 → 同样滚主列。

所以维护者看到的是「左栏会话列表与右栏轨迹不能滚」。会话页没有视口字段，溢出只画到页高、
末行折成 `＋N 个会话`；改动页与 todo 页同样用溢出读数代替滚动；轨迹页有 `Pane` 却没有滚轮入口。

**Desired behavior:**

判据一条：**指针落在哪个滚轮目标上，就滚哪个滚轮目标**；滚轮目标从内到外是 **浮层 → 平铺格 → 栏**。

1. **浮层**：指针在浮层矩形里就归浮层。模型选择器与 `/`、`@` 候选菜单的滚轮**移动高亮**
   （与问卷滚轮同一条语义）；详情覆盖层**框内滚详情、框外滚下面那栏**；问卷与中间模态保持
   今天的样子；文件查看器仍全吃指针（nvim 自己处理滚轮）。
2. **平铺态**：每格是一个滚轮目标。指针在哪格就滚**哪一格的对话视图**，不换前台。
3. **左栏**：五页各有一份视口（会话、调用量、todo、文件、改动）。装不下才滚，装得下时滚轮
   归它但不动。栏内页签条与空白算左栏。
4. **主列**：标签态滚焦点会话的对话视图（今天的行为不变）。
5. **右栏**：轨迹滚自己的 `Pane`；流程页也有视口。栏内页签条与空白算右栏。
6. **无滚轮目标**：输入区、提示行、状态行、回合条、顶部页签条上滚轮**无动作**（今天它们兜底滚
   主列，这一条改掉）。栏不在屏上时（左栏收起、右栏隐藏、平铺态没有左栏）指针所在的下一层接。
7. **步长**：列表页（会话 / 文件 / 改动 / todo）与流程页一格 1 行；正文页（对话视图、轨迹）
   一格 3 行，沿用 `pane::WHEEL_ROWS`。文件页的 1 行不变。
8. **滚轮是纯阅读手势**：会话页与改动页的滚轮只动视口、不动焦点行；键盘 `↑` / `↓` 移焦点时
   视口把焦点行带进来（与文件页 `files_scroll_to_focus` 同一条）。轨迹页的滚轮只动视口，
   不动块选中、不拿键盘。平铺态滚非焦点格不换前台。
9. **溢出读数退场**：会话页 `＋N 个会话`、todo 页 `＋N 项`、改动页 `还有 M 处改动` 三处不再画；
   不另加总数字读数。
10. **滚动条**：每栏内容区右缘一列，只画滑块（`█`、`MUTED`；视口不在底部时 `BOLD`），不画轨道
    与箭头；**只在滚动时出现**，该栏最后一次滚轮 1 秒内才画，过了消失（由既有 60ms 脉冲
    `TuiState::tick` 推进，不另起时钟）。主列那条也从常驻改成同样规则。出现与消失**不得引起
    重排**：主列的转录早就为它留过列（`TRAILING_COLUMNS`），用那一列；左栏与右栏没有预留，
    画在内容区最右一列上（覆盖 1 秒），不改内容宽度。滚动条不可点、不进命中表。
11. **滑块位置自己算**：不用 ratatui 的 `Scrollbar`。它的分母是 `content_length − 1 + viewport_length`，
    `position = total − height`（贴底）时滑块停在轨道中段 —— 内容越短偏得越明显（100 行 /
    40 行视口 / 40 格轨道时滑块落在 17..29，轨底是 40）。改为：`v` 视口行数、`n` 总行数、
    `d = n − v`（`d == 0` 不画）；滑块长 `l = max(1, round(track × v / n))`；起点
    `s = round(top × (track − l) / d)` —— 顶部 `s = 0`，贴底 `s = track − l`。整数运算，不引浮点。

**Key interfaces:**

- `KeyboardLayer::handle_wheel(state, column, row, up)`：本次所有分派都落在这个方法的各层实现
  上；`wheel_dispatch` 的语义（第一层认领即停）不变。优先把「按矩形认领」收进各自层，不要
  在 `TuiState::mouse` 里另开一张坐标阶梯。
- `TuiState` 的矩形字段（`sidebar` / `sidebar_page` / `trace_rect` / `conversation_rect` /
  `modal_rect` / `detail_rect` / `picker.rect` 等）：仍守「这一帧真的画了什么就记什么」；
  缺的滚轮目标矩形（右栏流程页、左栏会话/调用量/todo 页区、平铺每一格、记号菜单）按同一纪律补。
- 平铺态需要一个「格矩形 → 会话 id」的映射（绘制时记），滚轮据此找到那一格的 `View`。
- 各页状态新增视口：`SessionsPage`、`ChangesPage`、`TodoPanel`、流程页（`flow` 那份状态）；
  文件页与两个 `Pane` 已有。视口是渲染器状态：活进程内、不落盘、不跨会话（会话页与改动页是
  进程级的，与页签同类）。
- `draw_scrollbar` 从「对话视图专用」泛化成「给一个窗格/视口 + 一条列」；1 秒窗口做成常量。
- `pane::WHEEL_ROWS` 与列表页的 1 行：两档常量各归各的，不要互相借用。

## 明确不做

- 键盘翻页键（`PgUp` / `PgDn` / `Ctrl-G`）的归属：本次只加滚轮。
- 顶部页签条上的滚轮。
- 文件查看器的指针规则（它是一块外来的屏幕）。
- 回退鼠标捕获或改终端鼠标协议。
