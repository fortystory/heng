# 04: 左栏五页都有视口

Type: implement
Status: done
Blocked by: 02, 03
Part of: ../spec.md

**What to build:** 左栏五页各有一份视口，滚轮落上去滚的是这一页：

- `会话`、`todo`、`改动` 三页新增视口（文件页已有）；
- 文件页只接上滚动条，滚轮行为一个字节不变；
- 调用量页同样给视口（统一），内容通常装得下，所以表现为「归它但不动」；
- 三处溢出读数退场：`＋N 个会话`、`＋N 项`、`还有 M 处改动` 不再画；
- 滚轮是纯阅读手势：会话页与改动页的滚轮不动焦点行；键盘 `↑` / `↓` 移焦点时视口把焦点行
  带进可见区（与文件页 `files_scroll_to_focus` 同一条）；
- 滚动条用 03 的读法画在每页内容区右缘一列上，只在滚动时出现，出现与消失不改内容宽度。

- [x] 会话列表内容超过页高时，滚轮滚动视口、列表跟着动；末行不再出现 `＋N 个会话`。
- [x] 会话页：滚轮不改焦点行；键盘 `↑` / `↓` 移动焦点时，焦点行始终被带进可见区。
- [x] todo 页：滚轮滚动它自己的列表；`＋N 项` 不再出现；点开详情弹窗的行为不变。
- [x] 改动页：滚轮滚动它自己的列表；`还有 M 处改动` 不再出现；键盘移焦点时视口跟随。
- [x] 文件页：既有的滚轮行为（每格 1 行）与键盘焦点行为不变，只是多了滚动条。
- [x] 调用量页：指针落在它上面滚时，归它、不动；主列不动。
- [x] 左栏页签条与页内空白上的滚轮归左栏当前页。
- [x] 五页的滚动条都只在滚动时出现，停手 1 秒后消失；出现与消失时文字列数不变。
- [x] `cargo test` 绿；`cargo clippy --all-targets` 无新增告警。
