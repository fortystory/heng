# 06: 平铺态滚指针所在那一格

Type: implement
Status: done
Blocked by: 02, 03

**What to build:** 平铺态里每一格是一个独立滚轮目标。绘制时记下「格矩形 → 会话 id」，滚轮按指针
所在格找到那一格的对话视图并滚它，**不换前台**、不动会话页焦点。每格右缘也画滚动条（只在
滚动时出现，与三栏同一条读数），出现与消失不改格内文字宽度。

- [x] 两格平铺：指针在**非焦点格**上滚，那一格的对话视图动，前台不变、会话页焦点不变。
- [x] 指针在**焦点格**上滚，行为与今天一致（滚焦点会话的对话视图）。
- [x] 一格滚动不影响另一格：另一格的视口一个字节不动。
- [x] 每格右缘的滚动条只在滚动时出现，停手 1 秒后消失；出现与消失时格内文字列数不变。
- [x] 指针落在格间的虚线或平铺区空白上：无动作。
- [x] `cargo test` 绿；`cargo clippy --all-targets` 无新增告警。
