# 0025. 右栏不止一页：轨迹之后加流程

- 状态：接受（2026-10-19）
- 背景：[`.scratch/flow-page/spec.md`](../../.scratch/flow-page/spec.md) 与
  [`prototype/README.md`](../../.scratch/flow-page/prototype/README.md)（三种形状里 A
  「等权全图」定案）。它推翻 [ADR 0024](0024-trace-lives-in-the-right-rail.md) 的「右栏里
  只有一页 —— 轨迹」那半句，其余决定一个字不改。

## 决定

右栏有**两页**：`轨迹`（第一页，它的家）与 `流程`（第二页）。顶部一条页签条负责切页，
画法与左栏页签条同种；选择是**纯视图偏好** —— 只活一次进程、不落盘、不跨会话，只能点、
不给键位（`Ctrl-V` 仍然只管开/关右栏）。代价是页签条吃掉 3 行，轨迹页跟着少 3 行。

- **流程页的内容**：agent 一次回合的五个节点（收到你的话 → 等模型响应 → 流式输出 →
  工具调用 → 回合收尾）的纵向轨道；当前节点展开至多两行子块；已过节点带停留时长；工具
  之后一条 `↺` 回边；底部**高度固定**的说明区与回合统计。空闲时轨道定格上一回合。
- **数据来源**：只读 TUI 已经收得到的东西 —— 进流事件、`MessageCompleted.first_token_ms`
  （[ADR 0020](0020-first-token-time-rides-the-completion.md)）、
  `ToolCallCompleted.duration_ms`、会话三态、增量事件。**不新增事件、不动 `agent`、不改
  投影**。相位机只认主发言者的回合事件，执行者与讨论者的同名事件一律忽略。
- **高度阶梯**：右栏内容区 `≥18` 行全量、`14–17` 丢统计、`10–13` 窗口化（当前节点 ±1，
  被裁端画 `⋮`）、`<10` 只留当前节点与一句话。

## 替代方案

- **塞进左栏页签**：左栏是会话读数，40/28 两档，流程页的轨道加说明要 42 列起；而且左栏
  已经有五签。
- **主列再开一页**：主列只剩对话视图（票 16 的决定）。流程是**旁读**，不是正文；再开页会
  把「主列只有一页」这条纪律失守。
- **新增事件让相位更精确**（预检 / 组装 / 预算 / 权限门的逐步骤）：那会把渲染细节写进
  事件流，动 `log.jsonl`、投影与回放。本轮明确不做 —— 要的话另开一张图。

## 后果

- ADR 0024 的宽度档、`Ctrl-V` 语义、轨迹的宽度来源都不变；只回改「只有一页」那半句。
- 流程页与轨迹的时间轴横带是同一份事实的两处投影：都从事件流推，**不另存状态**。
- `docs/render.md` 的「右栏」一节补两页；真机清单多一条（页签点击与颜色、矮终端降级）。
