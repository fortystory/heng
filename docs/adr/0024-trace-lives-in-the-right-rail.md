# 0024. 轨迹的落点：主列 → 右栏（第三版）

- 状态：接受（2026-10-17）
- 背景：[`.scratch/session-panes/spec.md`](../../.scratch/session-panes/spec.md) 的冻结项 6；
  来路是 [`.scratch/session-panes/issues/12-grilling-main-column-after-move.md`](../../.scratch/session-panes/issues/12-grilling-main-column-after-move.md)
  与 [`.scratch/session-panes/issues/04-prototype-right-rail-trace.md`](../../.scratch/session-panes/issues/04-prototype-right-rail-trace.md)。
  第一版「轨迹是主列独立页」、第二版「主列两页签互翻」都退役了。

## 决定

**轨迹视图的家是右栏**：右栏是屏幕右侧一栏（40 / 28 / 隐藏三档），里面只有一页 —— 轨迹。

- 主列只剩**对话视图**一页：没有主列页签条、没有页签提示行，转录直接从顶部页签条下面开始。
- `Ctrl-V` 从「翻主列两页」改成「开 / 关右栏并把键盘交给它 / 交还输入区」；提示行因此有
  两套：键盘在输入区是 `KEY_HINTS`，在右栏是 `RAIL_HINTS`（末条 `ctrl-v 交还`）。
- 轨迹的**宽度来源**只有右栏内宽：两态（标签 / 平铺）切换不重放它，只有屏幕宽度跨右栏档
  （如 119 → 122）才重放一次；时间戳列只在 40 档画，28 档是缩略索引。
- 行尾用量不再画进轨迹：要读用量去详情覆盖层或每回合合计。
- 右栏在平铺态照开；左栏在平铺态自动收起（格宽下限 32 需要那些列）。

## 为什么两边不都放

- 两份投影 = 两份宽度来源与两次重放：同一行在两处按不同宽度折行，于是「同一份块」在屏幕
  上出现两种排法，复制与折行语义各说各话。
- 平铺态每格只有对话视图（冻结项 8）：主列里的轨迹页在平铺态没有位置，留着只会多一条
  「这一页只在标签态可用」的分支。
- 主列的宽度被左栏与右栏挤到 50 列上下；轨迹的行首时刻要九列，九列在那种宽度里占掉了
  一条读法，而右栏 40 档刚好放得下。

## 后果

- 「轨迹永远可达」这条旧承诺改成「屏幕宽到能开右栏时可开」：窄到放不下时 `Ctrl-V` 只回
  `右栏放不下`，一个字节都不动布局（票 14）。
- 轨迹的键盘归属与「键盘在谁手里」合并成同一件事：右栏拿住键盘时提示行换表，`Esc` 退完
  「搜索 → 过滤 → 选中 → 交还」（票 16、票 20 的既有阶梯）。
- 详情覆盖层从轨迹打开时，关掉把滚动位置还原给**右栏**；这份归属跟着会话走（票 22）。
