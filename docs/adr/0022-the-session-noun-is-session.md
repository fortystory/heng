# 0022. 会话的量词是「会话」，不是「场」

- 状态：接受（2026-10-12）
- 背景：[`.scratch/chinese-ui/issues/09-session-noun.md`](../../.scratch/chinese-ui/issues/09-session-noun.md)；
  来路是 [`.scratch/session-tab/issues/32-close-interaction.md`](../../.scratch/session-tab/issues/32-close-interaction.md)
  那一轮访谈（Q13–Q19）。

## 决定

界面、注释、文档与测试里，会话的量词一律说「**个 / 会话**」：`2 个会话`、`这个会话`、`多个会话`。
原先那个「场」退休。

- **宿主表读数补回它原来承担的区分**：盘上跑过的会话（store，页区那句 `还没有历史会话`）与进程里
  活着的会话（宿主表）本来靠「场 / 会话」两个词分开，现在靠「**已装载**」：宽档
  `已装载 2 个 · 1 个在跑`；窄档（左栏 28 列）只报 `2 个 · 1 个在跑` —— 那三个字放不下，会挤掉
  同一行右端的 `新建` / `关闭`。
- 终端标题的两段：`N 个待答` / `N 个跑完`；会话页末行：`＋N 个会话`。
- 「场外」→「**后台**」（前台 / 后台本来就成对）；「一场讨论」→「**一次讨论**」。
- **固定搭配不动**：开场、清场、现场、立场、退场、进场、收场、当场、在场、场景、场面、场合。

## 迁移范围

`src/`（含代码注释）、`CONTEXT.md`、`docs/`、活跃的 `spec.md` / `map.md`、`tests/` 的断言。

**不动**历史票（`.scratch/**/issues/`）与 `docs/adr/` —— 那是记录，里面会一直看得见「场」，这篇
背景一节就是为此而写。其余 feature 的 spec 里也仍有旧量词（这一轮只迁了本 feature 的 spec/map
与 `docs/`），逐份回改随各自的文档回改票。

## 后果

`scripts/check-language.py` 多一条**量词纪律**：禁用搭配（`一场` / `这场` / `N 场` / `场外` …）
一旦回潮就红；固定词与带引号的元语言引用（讨论这个词本身）豁免。
